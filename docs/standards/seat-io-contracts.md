# 席位 I/O 契约与全局责任（seat-io-contracts）

> 性质：**交接即验收**总则+十席四要素（DR-030）。原则：失控=不合格交付物在席位间自由流动；对策=凡交接必过下游输入把控，不合格即拒收退回；一切交接物有格式真源，凭证据收货（issue 号/文件路径/测试名），不凭感觉。

## 0. 全局责任条款（大局观 · 超越上下游，四条具体义务）

1. **跨席找茬义务**：每席每次交接/回顾至少提一条跨席摩擦观察（或明示"本轮无"）；发现问题不受上下游限制——UI 席发现主策划验收点不可测，可直接提给主策划并备案制作人；
2. **流程提案权平等**：任何席位可随时提流程改进提案（issue 打 `process` 标签，一页纸：现状/摩擦/改法/代价），制作人按里程碑批量裁决；
3. **逃逸缺陷共担复盘**：缺陷按"漏过的所有卡口"共担（引入/漏检/逃逸三席同复盘同出改进项），禁只追下游实施席；
4. **下游省工自问**：每席交付前自检"这个交付让整条管线更快/更准/更稳了吗"——此问句并入下表各席输出把控。

## 1. 席位契约表

| 席位 | 输入（触发+材料） | 输出（交付物+真源） | 输入把控（拒收→退回） | 输出把控（自检+下游省工自问） |
|---|---|---|---|---|
| 制作人 | 试玩反馈原话/各席提案/[change] 请求/回顾数据 | 排期 issue 清单+DR 清点/优先级与双签/里程碑四行式 | 反馈不可还原→退回补信息；提案无 DR 依据或越冻结口径→退回 | issue 过 lint+双检才可认领；[change] 未双签不下发 |
| 主策划 | DR 裁决/分诊后反馈/制作人范围 | 设计稿（GDD 增量）/issue 规格（验收锚+≥3 验收点）/[P] 试玩脚本 | DR 未裁不开工（先走会议）；与真源冲突→停下上报 | 验收点三要素齐；界面类附映射表行；[P] 三段式 |
| 数值策划 | 硬约束清单/参数需求/断言区间 | 参数表（JSON 形态+占位带）/标定报告 | 常数无出处注释→退回（DR-029 C-4） | 给推演不给裸数字；万次模拟防越界 |
| 文案策划 | 文本需求（场景+长度预算）/术语触发需求 | texts.json 键值（键名规范+max_len）/敏感词表 | 无使用场景或超预算→退回 | 三断言进 verify 才算交付 |
| UI/UX | 界面类 issue/交互 DR | 状态-视觉映射表行/反馈链路清单/IA 与折叠序 | 无状态清单或无交互 DR→退回 | 触屏≥48px；三态覆盖；走查附 PR |
| 测试工程师 | [T] 验收点清单/架构分层图 | 测试策略/GUT 用例清单草案/门禁草案 | [T] 无 GUT 落点（不可测）→退回主策划改写 | 只定策略不写业务代码（契约红线） |
| 主程序 | 过检 issue/测试草案/ADR | 代码 PR（分层合规）/验收点自证表/ADR 增量 | issue 未过检→**拒领**；验收点缺失→退回补规格 | verify 全绿+对账断言+自证逐条引用 |
| 试玩分诊 | 用户原始反馈 | 分诊表（类别/定性/去向）/还原记录/归档条目 | 原话逐字保留（禁意译） | Bug 类先复现；转化类量化代理指标 |
| 圆桌主持 | 议题包/独立提案/画像审视 | 约束先行/裁决草案/终裁纪要 | 提案缺开放问题/越冻结口径→退回 | 否决留痕；数值硬约束可执行；[change] 显式标注 |
| code-review | PR（含自证表） | 双轴评审结论（标准/需求） | 无自证表→打回不评审 | 引用验真（grep 用例/截图落盘）；不过=合入前置失败 |

## 2. 失败模式对照（本契约封堵的已发生病）

| 已发生缺陷 | 契约封堵点 |
|---|---|
| F2 issue 空心 | 制作人输出把控（lint+双检）+主策划内容审 |
| F3/F4 规格漏译 | 主策划验收锚+≥3 条验收点+DR 清点 |
| "指派没反应"类 | 主程序拒领权（未过检 issue 不接） |
| 测试在场不拦截 | 测试输出绑验收点（场景挂靠 [T] 项） |
| 自证走过场 | code-review 引用验真+GUT passing 行 |

## 3. 维护

- 模板/契约是活文档：每批试玩复盘"模板增删+流程水位"合并节上修订；字段说不出"防哪条已发生缺陷"即删；连续 2 里程碑零反哺自动降可选；
- 里程碑 handoff 附流程水位段（哪些检查单生效/待启用）。
