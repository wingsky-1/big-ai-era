# UI 反馈链路验收清单真源（ui-feedback-checklist）

> 性质：界面类 issue 强制附件（DR-030）。封堵"可见了无反馈"类缺陷（v0.1.3：指派无反应/暂停态不可辨）。
> 用法：每个可交互元素逐项勾选；缺项不许过检。

## 1. 反馈三态（每交互必检）

- [ ] **即时态**：操作瞬间有反馈（按下态/涟漪/声音占位）——操作被"听见"；
- [ ] **结果态**：操作生效后有可观察的终态变化（文本/计数/卡片刷新）——结果被"看见"；
- [ ] **禁止态**：不可用时置灰且原因可查（悬停/长按提示）——拒绝被"理解"。

## 2. 链路断言（每交互必检）

- [ ] 操作→信号：成功路径发信号（GUT：`assert_signal_emitted`）；
- [ ] 信号→UI 刷新：监听方实际更新（GUT：调 presenter 后断言视图键值）；
- [ ] 失败路径静默可辨：拒绝时不刷新但有禁止态反馈；
- [ ] **键名契约**：presenter↔view 共享键收单点常量源（DR-030 m3），禁裸字符串新增。

## 3. 三态库（空/加载/错误，组件级通用）

- [ ] 空态：无数据时显示引导性空态文案（非空白）；
- [ ] 加载态：异步内容有占位指示；
- [ ] 错误态：失败有可读提示+恢复路径。

## 4. 移动端专项（UI 类 PR 必附）

- [ ] 触屏目标 ≥48px（DR-015）；
- [ ] 竖屏 375×667 走查：折叠序按心智权重倒序，工作区永不折叠；
- [ ] 安全区/刘海适配目检；
- [ ] capture_screens_web 移动视口截图存档（人审，不比像素）。

## 5. 文案与主题

- [ ] UI 禁内联文案串，一律取 texts.json/data 键（防键名失配在文案层重演）；
- [ ] 主题收口：色/字号走 src/ui/theme/ 资源（PR 附主题变更声明）；
- [ ] 常显标识文本+图形双通道（色盲安全）。
