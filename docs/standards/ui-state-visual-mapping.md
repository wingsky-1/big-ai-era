# 状态-视觉映射表真源（ui-state-visual-mapping）

> 性质：**验收点来源而非文档**（DR-030）——每行=界面类 issue 的验收 checkbox+信标断言名；改界面必走 issue→先改表→再改码，表随验收点同生共死。
> 依据：2026-09-08 复盘圆桌 V2.2 §二；三类已发生缺陷（注册未实现/实现了不可见/可见了无反馈）的模板化封堵。

## 1. 列定义

| 列 | 说明 |
|---|---|
| 状态值 | 游戏状态/面板状态枚举（如 user_paused / blocked_by_card / speed=2x） |
| 触发源信号 | 哪个信号驱动此状态（resources_changed / progress_ticked / …） |
| 常显表现 | 持续可见的视觉呈现（非按下瞬时高亮） |
| 瞬时表现 | 按下/操作瞬间的反馈 |
| 禁用表现 | 不可用时的视觉（置灰+原因可查） |
| 信标断言名 | selftest_web 信标属性值（**信标落地前填"待回填"**，lint 豁免该列） |
| 竖屏折叠形态 | 375×667 下的降级呈现（工作区永不折叠，DR-009/015） |

## 2. 起始表（本 v0.1.3 反馈缺陷对应行）

| 状态值 | 触发源信号 | 常显表现 | 瞬时表现 | 禁用表现 | 信标断言名 | 竖屏折叠形态 |
|---|---|---|---|---|---|---|
| user_paused=true | GameClock 用户暂停 | 主台常显"已暂停"标识（文本+图形双通道，色盲安全），遮罩之上可辨 | 暂停键按下反馈 | — | 待回填 | 资源栏副行位显示 |
| user_paused=false | set_paused(false) | 无暂停标识，流速档位常显当前档（1x/2x/4x） | 播放键按下反馈 | — | 待回填 | 同上 |
| z2 自动暂停（周报/决策卡） | week_settled / decision_pending | 常显"自动暂停"标识，区别于用户暂停 | 弹层推入动画 | — | 待回填 | 同上 |
| 员工 idle/assigned | resources_changed（assign/unassign） | 主台员工实体卡：名/状态/在岗位；指派后 0.5s 内刷新 | 卡片按下反馈 | 无 idle 员工时指派入口置灰+原因 | 待回填 | 折叠为横滑行或紧凑网格，触屏≥48px |
| PAUSE_MENU 开 | dock 暂停键 | 面板实例化可见（继续/重开/速率），Esc 可关 | 遮罩淡入 | — | 待回填 | 居中弹层自适应 |

## 3. 维护纪律

- **先改表再改码**：任何界面变更的 issue 必须引用将变更的表行；实施 PR 同步更新本表，code-review 核对；
- **信标名进对账**：删状态不同步删信标=对账断言暴露；
- **三态覆盖**：空/加载/错误（禁用）态缺一的行不许过检（引用 ui-feedback-checklist.md）；
- 新增界面=新增行；废界面=删行并留 issue 链接痕。
