# 论文系统蓝图（Blueprint: Papers）

> 状态：[讨论稿] ｜ 阶段：P0 已具形态，P1/P2 目标形态如下 ｜ 读取序：README → 本文件

## 一、定位

**玩家视角**：论文不是"刷声望的任务"，而是我的研究方向——复现哪篇、深耕哪个领域，决定我实验室的"学术画像"；论文有谱系，我的工作有出处、有影响、有传承（我引用了谁、谁引用了我的）。

**设计原则**：任务=可选的论文主题（方向选择=策略表达）；论文与科技树/模型/芯片**你中有我、我中有你**——树解锁论文选题、论文产出点亮树的燃料、论文成果带动模型出分、算力支撑论文实验（共生环的一环）；所有论文效果走确定性或已登记随机域（零新随机源）；**任何"域 RP 权重"类设计必须先过数值推演**（防"最优解唯一"伪决策重演）。

## 二、目标形态（终态）

1. **论文=研究方向**：复现/研究任务带领域标签（对齐/蒸馏/记忆/多模态/工具…），选题影响：该域 RP 累计、迷雾翻动（对齐竞对论文外溢的确定性规则表）、后续任务线解锁（领域内选题→深挖链）。
2. **n 维质量画像（论文的核心感知之一）**：每篇论文完成时产出 **n 维质量评分**（如创新/严谨/影响/复现性，维度集随科技树与员工扩展）；n 维加权合成单值"论文质量分"；n 维可读可决策——"这篇创新高但复现性差"= 下一步往哪个维度补的决策依据；**n 维变化与任务进度同为主台重点感知**（配合 UI/UX 蓝图重点感知排序）。
3. **论文谱系**：已发论文存档为"我的论文列表"（标题/领域/影响力/引用了谁/n 维画像），单局内可回看（手记）；竞对论文也入谱（"他引用了我的结果"叙事）。
4. **外溢联动**：竞对论文 → 确定性翻雾（表驱动，零 RNG）；假 arXiv 周报装饰行（确定性轮换，零效果）承接"学术圈氛围"。
5. **术语质感**：全部文案走文本真源，考据修正优先（验收尾款/消融全绿/权重流出——反对"灵光一闪"式泛化叙事）。

## 三、GDS 可复用语言

- **题材选择=策略棋盘**：GDS 类型×题材组合表公开可查；本作论文方向选择承接同一"读表"精神；
- **组合匹配**：GDS 题材配谁/配什么平台；本作论文方向×员工特质×基座的对照表（见员工/模型蓝图）；
- **收集谱系**：GDS 员工池是收集品；本作论文谱系是智力档案（轻量收集，不建重系统）。

## 四、阶段路径

### P0 骨架：任务即论文
- 内容：复现/研究/课题三类任务（产出 RP+资金）；论文外溢翻雾（竞对确定性规则表）；假 arXiv 装饰行。
- 判定 [P]：任务能讲出"我在复现什么"；竞对发论文后迷雾有反应（探索感成立）。

### P1 深化：论文=方向选择 + n 维画像 + 共生环
- 内容：任务带 domain 标签（选题池按域划分，**选题池随科技树点亮扩展**——树开哪些域，论文就能选哪些方向）；论文列表/谱系存档；**n 维质量画像随论文完成展示**（创新/严谨/影响/复现性，n 维可读、加权合成论文质量分）；选题→域 RP 累计→迷雾联动；**论文成果回喂**（论文影响力→模型出分加成/芯片实验效率）；文案考据批（消融/尾款/权重流出叙事）。
- **前置**：先做 domain 标签+选题池+n 维画像（独立可验）；**"域 RP 权重"（主域 1.0/副域 0.5~）与 n 维权重须先做数值推演**——验证"多域混合 vs 单域专精""多维均衡 vs 单维专精"的期望收益非唯一最优解，再决定是否落地（防重演教科书伪决策）。
- 判定 [P]：选择研究方向有真实取舍；我的论文列表像"学术简历"且每篇有 n 维画像（"这篇是复现性强的稳稿"）；点亮新树节点后论文池确实"开了新方向"。

### P2 长线：论文谱系 + 引用网络
- 内容：引用网络（谁引用了我的结果）；联合课题（与大厂/高校合作选题）；论文影响力成为阶段与终局指标之一；**论文谱系与模型谱系呼应**（论文→模型→论文的引用链）。
- 判定 [P]：论文列表像一部"学术编年史"；终局时能回看"我从复现论文走到定义方向"。

## 五、系统联动

- 科技树（域 RP 权重→点亮路径；树解锁的域=论文选题池）→ **共生环：论文↔树**（与芯片/模型构成"论文→树→算力→模型"闭环，见 README 矩阵注）
- 竞对（论文外溢=探索驱动）→ 对手推动我探索
- 员工（哪些研究员适配哪些方向）→ 人岗决策
- 模型（论文方向→基座选择→出分）→ 出分链
- 经济（课题/复现收入）→ 劳务收入
- UI/UX（论文列表/谱系视图）→ 呈现层

## 六、开放问题

1. "域 RP 权重"防伪决策的数值推演结论（多域 vs 单域期望收益比较）——未推演前不落地；
2. 引用网络是否进 P2 范围（还是只做单向"我引用了谁"）；
3. **论文 n 维画像的维度集与权重**：创新/严谨/影响/复现性 4 维起步？每维由什么决定（选题×员工×科技）？n 维与"域 RP 权重"是否同源（防两套独立曲线打架）——数值推演先行；
4. 论文质量分与模型出分加成的关系（论文 n 维中"影响"维→模型加成的换算，与共生环闭环同批推演）。
