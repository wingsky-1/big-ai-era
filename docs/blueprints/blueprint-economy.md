# 经济系统蓝图（Blueprint: Economy）

> 状态：[讨论稿] ｜ 阶段：P0 已具雏形，P1/P2 目标形态如下 ｜ 读取序：README → 本文件

## 一、定位

**玩家视角**：钱是真实的压力也是真实的回报——我会真切地"穷过"，但每次危机都有可见的选项（借/卖/接活/降本），不会毫无预兆地死；我做的模型能变成钱（不只是排名），收入结构随阶段进化（劳务→产品→资本）。

**设计原则**：会穷、能自救、能变现；收支永远可对账（因果可见）；救济=抉择不是惩罚；产品化是长线主线。

## 二、目标形态（终态）

1. **三阶段收入结构进化**：
   - 实验室期=劳务（接课题/复现）+ 固定支出（工资/运维）；
   - 独角兽期=融资脉冲（一次性外来资本+稀释）+ 产品收入萌芽（模型部署）；
   - 上市期=产品常量收入（API 部署）+ 资本动作（IPO 一次性）。
2. **产品化变现（主线）**：训练成品可**部署**为 API 常量收入（**定价与模型 n 维画像挂钩**——推理/速度/成本维强者定高价，弱维打折）；可选"公开权重（+影响力）/商业授权（+资金）"二选一（把出分瞬间变成经济决策点）；被竞对反超会惩罚收入（×~0.85 且衰减加深）——产品经济与竞对守卫联动。
3. **危机救济三件套**：贷款（宽限+分期+利息，还清可再借，提前还清减息）、设备出售、接私活（全局限次+冷却+收入随危机递减）；破产=本局结束重开+负债计入判定（防贷款=套现）。
4. **名气杠杆（影响力出口）**：影响力可消耗换市场系数（类似 GDS 宣传费），与融资/门票共用一口（防三口互挤）。
5. **对账纪律**：唯一过账口+周报对账闭合+预警线常显（"本周亏 X，还能撑 X 周"、贷款入口预警窗口内可见）。

## 三、GDS 可复用语言

- **销量×售价=产品脉冲**：收入来自发售（一次大脉冲）而非纯劳务；本作用"部署/授权"承接产品化；
- **刚性支出**：工资+租金制造持续压力；本作工资+运维+（扩建）房租；
- **贷款救济**：危机变抉择；本作宽限+分期+提前还清减息（防剥削）；
- **会穷能自救**：不会毫无预兆地死，但真切穷过。

## 四、阶段路径

### P0 骨架：收支对账 + 生死线
- 内容：劳务收入（课题/复现）+ 固定支出（工资/运维）+ 破产/警告线常显 + 周报对账闭合 + "还能撑 X 周"文案。
- 判定 [P]：玩家随时能说出"这周亏/赚多少、还能撑几周"；5 分钟内收支可读。

### P1 深化：产品化 + 危机救济
- 内容：模型部署（API 常量收入）+ 授权二选一；贷款（宽限+分期+利息+还清再借）/设备出售/接私活（限次+冷却+递减）；名气杠杆（影响力出口换市场系数）；被反超惩罚收入。
- 判定 [P]：濒死盘活看得见（贷款救活一局并付出代价）；"我训的模型开始赚钱"有体感；救济不能无限续命（摆烂还是会死）。

### P2 长线：资本与阶段深化（单局内）
- 内容：融资脉冲（稀释+一次性资本）、IPO、财报日事件节律；支线常驻（算力出租/企业咨询/开源赞助）；资本结构在单局内进化（劳务→产品→资本三阶段收口）。
- 判定 [P]：阶段转化有"公司长大了"的体感；终局时回看经济结构"从接单到上市"的完整弧线。（不做多周目继承/往年卷。）

## 五、系统联动

- 模型（部署/授权产品化）→ 收入源
- 竞对（被反超惩罚/价格战）→ 收入风险
- 时间（周账本/财报节拍）→ 结算节奏
- 员工（工资/培训/签约金）→ 支出面
- 芯片（档位购买/算力出租）→ 开支与支线收入
- 科技树（降费类节点）→ 成本杠杆
- UI/UX（现金流曲线/常显预警）→ 可视化

## 六、开放问题

1. "授权二选一"（公开权重+影响力 vs 商业授权+资金）与蒲公英域"权重流出"叙事的边界；
2. 名气和影响力双资源是否需要合并（避免两套声望曲线互相打架）。
