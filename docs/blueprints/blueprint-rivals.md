# 竞争对手蓝图（Blueprint: Rivals）

> 状态：[讨论稿] ｜ 阶段：P0 已具形态，P1/P2 目标形态如下 ｜ 读取序：README → 本文件

## 一、定位

**玩家视角**：深巷科技是活生生的宿敌——它有发文节奏、会抢占我先发、会涨价占我便宜、会想挖我的研究员；排行榜上的名次是看得见的张力，我不只是被时间推着走，是被对手逼着走。**但对手不常驻主界面**——主界面的主角是我自己的任务进度与员工属性变化（那才是最刺激感官的），对手在关键时刻（发版/反超/破纪录/周报）现身，制造"回头一看被追上了"的惊觉感。

**设计原则**：对手=脚本化里程碑+扰动（**永不引入博弈 AI**——确定性验收是硬红线）；守卫张力分层（未满配被超/接近满配险胜/满配安全）；对手行为必须**有可见后果**（不只是分数）；作恶有代价（不可被刷）；**感知位次**：对手信息从"主界面常驻条"退到"关键时刻显现"（周报/事件/悬停），把主界面视觉预算让给任务进度与属性变化。

## 二、目标形态（终态）

1. **多动作时间线**：竞对按时间线推进多类动作——论文（引发迷雾外溢）、发版（SOTA 威胁）、涨价（压缩我方 deploy 收入）等；同类动作有多发/递增形态。
2. **守卫张力三层**：对手 L1–L4 分数逐渐逼近玩家封顶值，但不逾越（禁超玩家封顶）；未满配→被超，接近满配→险胜，满配→安全守成。
3. **行为后果层**：
   - 抢发判定：同周双发="独立工作撞车"叙事（禁"你抢到了"）；发版先序≠分数平局；
   - 价格战/配额收紧：对手涨价→我方 deploy 收入乘数下降；我方有反击决策（降价抢客户/绕道）；
   - 挖人：对手挖我方研究员→涨薪留人 counter-offer 决策（优先于竞业）；
   - 传闻池：对手动向的传闻（±窗口投放）制造情报博弈（可预判=可针对）。
4. **宿敌分工**：多对手各有职能（总分榜宿敌 / 效率榜影子 / 后期势力），不同对手=不同压力面。
5. **落后可见**：周报一行"为什么落后"（差距/原因），不制造黑箱。
6. **感知位次**：对手分数/差距**不常驻主界面**——主界面聚焦任务进度与员工属性变化；对手信息在关键时刻显现（发版预警/被反超/破纪录时的弹层或周报头条；SOTA 榜/详情页可随时查）。玩家时不时"回头一瞥"发现被逼近=惊觉感，而不是被永远在旁的对手条压着。

## 三、GDS 可复用语言

- **活的对手=压力源+目标参照**：GDS 对手会抢占题材/大奖（市场窗口有限）；本作用抢发/涨价承接；
- **排行榜张力**：GDS 销量/评分榜；本作 SOTA 榜+（P2 影子效率榜）；
- **时间压力**：对手发版周是"守卫时刻"，让玩家感到机会在关闭。

## 四、阶段路径

### P0 骨架：时间线脚本 + 守卫张力
- 内容：单一宿敌按时间线推进（论文/发版/涨价动作）；分数逼近但不超玩家封顶；逼近预警（黄灯提前量/红灯 2 周零误报）；破纪录与反超播报；**对手信息收进"关键时刻显现"**（主界面只留轻量入口，不常驻对手条）。
- 判定 [P]：玩家能说出"下一个威胁在几周后、差多少分"（查得到，不被主界面追着看）；被超有"被逼出紧迫感"而非"挫败感"；主界面视觉重心=任务进度/员工变化。

### P1 深化：行为后果 + 宿敌分工
- 内容：抢发判定（撞车叙事）；涨价→deploy 收入惩罚+反击决策卡；挖人→留人 counter-offer；传闻池投放；第二对手登场（效率榜影子：以效率而非总分施压）；落后"为什么"一行进周报。
- 判定 [P]：对手行为让我调整决策（提前发版/攒钱反击/加薪留人）；两个对手的压力面不同（一个逼分数、一个逼效率）；对手事件是"插曲"而非"背景噪音"。

### P2 长线：竞对生态
- 内容：第三对手（后期势力）+ 多对手同场（走专项评审——多竞对同场是已知红级，须先过复议）；竞对年度复盘（谁今年最强）；竞对与收集（宿敌档案）。
- 判定 [P]：单局内不同阶段面对不同劲敌压力面；"这一局赢过谁"成为可讲的战绩。（多竞对同场是否实现取决于版本排程，不做跨局继承。）

## 五、系统联动

- 模型（SOTA 守卫/抢发）→ 分数对决
- 经济（涨价/挖人→收入与人才成本）→ 行为后果
- 科技树（论文外溢翻雾=竞对推动探索）→ 探索驱动
- 时间（发版周=守卫节拍）→ 危机节拍
- 随机（± 扰动是守卫张力的随机源之一）→ 不引入第 4 RNG 域
- UI/UX（竞对轻量入口/预警灯/对决曲线——查看时展开，不占主位）→ 呈现层

## 六、开放问题
