# 模型系统蓝图（Blueprint: Models）

> 状态：[讨论稿] ｜ 阶段：P0 已具形态，P1/P2 目标形态如下 ｜ 读取序：README → 本文件

## 一、定位

**玩家视角**：模型是我的作品——训练不是"等进度条"，而是有墙钟、有 checkpoint、有波折的科研旅程；出分瞬间是仪式（"这是我训的模型"）；成品有生命周期（可部署赚钱、可迭代升级、可收藏回看）。

**设计原则**：最长等待段（训练）必须可感知（进度+区间+确定性 checkpoint 事件）；出分=作品结晶（命名仪式）；成品资产化（部署/迭代）但**分批落地**（防一次性装五个子系统）；任何迭代/新训练形态不得破坏出分饱和护栏；**模型与科技树/论文/芯片你中有我、我中有你**——树解锁的基座才能训、论文方向决定训练实验、芯片档位决定能训多大，模型成果又回喂影响力与收入（共生环的一环）。

## 二、目标形态（终态）

1. **n 维质量画像（模型的核心感知）**：每个模型出分时展示 **n 维质量评分**（如 推理/知识/对话/速度/成本，维度集随基座与科技树扩展）；**n 维加权合成单值 score**（守 SOTA 守卫带）；n 维本身玩家可读可决策——"这个模型推理强但速度慢"= 下个模型往哪个维度优化的决策依据；n 维变化=最刺激感官的感知之一（配合任务进度）。
2. **训练可感知**：训练进度精确到周与区间；训练 50% 处确定性 checkpoint 卡点（墙钟事件叙事：损失回滚/消融提前，零数值掉落）；无每刻结算动画。
3. **出分仪式**：出分=截图时刻（**n 维画像+总分同屏揭晓**）；首次出分命名（参与而非可跳过）；峰值分数显示；SOTA 破纪录时刻强化。
4. **成品生命周期**：
   - 模型库：已训模型存档（命名/n 维画像/峰值分数/基座/曲线/部署状态）；
   - 部署：API 常量收入（门槛随对手最高分浮动，被反超会衰减；不同 n 维侧重→不同部署定价）；
   - 迭代（P2 立项评审）：同基座微调升级线（少卡时换小提升，**可定向强化某一维度**）；
   - 授权选择（P1/P2 评审）：公开权重（+影响力）vs 商业授权（+资金）。
5. **饱和护栏**：首达满分周次有下限断言；迭代收益上限卡在饱和阈值下（防"冲分永动机"）。
6. **考据纪律**：叙事用微调/LoRA/蒸馏/消融（不用 70b 幻觉表述）。

## 三、GDS 可复用语言

- **开发期蓄力+发售开奖**：本作训练→出分的节奏承接；
- **成品具象化**：GDS"这是我做的游戏"；本作"这是我训的模型"（命名仪式的力量来源）；
- **评分=公布瞬间**：GDS 发售评分；本作出分+sigmoid 曲线的"心跳"。

## 四、阶段路径

### P0 骨架：训练→出分→SOTA→命名
- 内容：基座（多档，多人上桌随基座）；训练固定时长+周进度；出分公式（员工力×科技×算力×基座质量）+SOTA 判定（严格大于/平局归霸主）；命名仪式+峰值展示；**n 维画像随出分同屏展示（先做 3~4 维：推理/知识/速度/成本，维度权重公开可读）**。
- 判定 [P]：第一次训练出分=想截图的时刻（总分+n 维画像同屏）；"我的模型叫 XX，推理强但速度慢"能说出口（n 维可读）。

### P1 深化：模型库 + 部署 + checkpoint + n 维决策
- 内容：模型库轻容器（出分后入档：命名/n 维画像/分数/基座/部署状态）；部署 API（常量收入+被反超衰减，**n 维侧重影响部署定价**）；训练 checkpoint 确定性卡点（50% 处墙钟事件）；首次命名仪式强化（L2 金框头条级）；**n 维画像可视化（条形/雷达）**。
- 判定 [P]：训练等待段有"快好了"的钩子；"我训的模型开始赚钱"有体感；"下个模型我要补它的速度短板"有决策依据（n 维驱动迭代）。

### P2 长线：迭代 + 授权 + 谱系
- 内容（**每项独立立项评审**）：微调迭代线（同基座二次训练，防破坏饱和护栏的数值约束先行）；授权二选一（公开权重+影响力 vs 商业授权+资金，叙事与供给口径需先行联标）；模型谱系（家族树：基座→微调→蒸馏后代）。
- 判定 [P]：模型有"成长后代"（迭代/蒸馏）的传承感；模型库在单局内即可积累出完整谱系。

## 五、系统联动

- 经济（部署/授权收入）→ 产品化主线核心一环
- 竞对（SOTA 守卫/被反超惩罚收入）→ 分数对决
- 科技树（解锁新基座）→ 出分上限（共生环：树开基座）
- 芯片（档位→能训多大模型）→ 算力门槛（共生环：算力撑训练）
- 论文（论文方向→训练实验；模型成果→论文影响力）→ 共生环
- 员工（多人上桌协作）→ 训练效率
- 时间（训练等待段=checkpoint）→ 节奏
- 随机（checkpoint=确定性事件，零掷骰）→ 无新随机源
- UI/UX（模型卡/曲线/仪式动效）→ 呈现层

## 六、开放问题

1. 授权"公开权重+影响力"=新影响力供给源，与供给口径（唯一来源）冲突如何消化（至少须修订数据供给真源，见 README 矩阵注）；
2. 迭代线与饱和护栏的数值约束（微调 Δscore 上限）何时推演——建议与科技树去 uniform 同批做（同一出分公式牵连）；
3. **n 维画像的维度集与权重**：哪些维度固定（推理/知识/速度/成本 4 维起步？）、每维权重是否公开、维度间 trade-off（推理↑ 速度↓）如何制造"定向优化"决策——数值推演先行；
4. n 维 score 合成与 SOTA 守卫带的关系：总分=加权和，各维度上下限如何标定使 n 维变化不破坏单值守卫张力（与科技树 tb 联标同批）。
