# 模型规格（Models Spec · 四件套）

> 蓝图依据：`blueprint-models.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格 → `texts-keys.md` / `numerics-master.md`
> 全局骨架：统一任务槽 4 个（**模型训练项目=任务槽三类项目之一**）；n 维画像=推理/知识/对话/速度/成本 5 维；score 合成守 SOTA 守卫带；四系统共生环一环（树解锁基座→芯片撑训练→论文给方向→模型回投影响力收入）。

## 0. 本模块定位

玩家视角：**模型是我的作品**——训练不是"等进度条"，而是有墙钟、有 checkpoint、有波折的科研旅程；出分瞬间是仪式（"这是我训的模型"）；成品有生命周期（可部署赚钱、可迭代升级、可收藏回看）。

设计原则：最长等待段（训练）必须可感知（进度+区间+确定性 checkpoint 事件）；出分=作品结晶（命名仪式）；成品资产化（部署/迭代）分批落地；任何迭代/新训练形态不得破坏出分饱和护栏。

## A. 交互细节规格

### A.1 结构定义（从零）

- **基座**（由树解锁，档位门槛由 chips 定）：每域一家族，P0 六基座（教学迷你 + 五域各一）：
  - 迷你基座（教学，无档位要求）；
  - 灵犀-1（对齐域→对话/推理向，T1）；轻羽-1（蒸馏域→速度/成本向，T1）；
  - 长河-1（记忆域→长上下文/知识向，T2）；执笔-1（工具域→工具调用向，T2）；
  - 通感-1（多模态域→多模态向，T3）；
  - P1/P2 各家族 2 号机（更高档位/更优画像），他者传闻基座=P2 大目标；
- **训练项目 = 任务槽项目之一**：占用 1 任务槽；上桌上限随基座（迷你 1 人→大基座 4 人）；训练时长=定值（不随随机波动）；
- **卡时消耗**：按基座档位每周消耗（chips-spec 周预算）；
- **出分判定**：score= n 维加权和（严格大于=破纪录；平局归霸主）；
- **成品生命周期**：出分→入模型库（命名/n 维/分数/基座/曲线/部署状态）→ 可部署（economy）/可迭代（P2）/可授权（P1/P2 评审）。

### A.2 玩家操作清单

**OP-MDL-01 发起训练（排入任务槽）**
- 入口：工作区"训练"轻键 → 基座选择列表（z1：基座卡=名/档位要求/工期/卡时/质量/上桌上限/n 维倾向）
- 操作：选基座 → 选上桌员工（1–n，上限随基座）→ 确认启动
- 即时反馈：启动键按下 → 项目入槽 + 工作区训练行即时出现（基座名+剩余 N 周+进度条）
- 结果：训练开跑（占 1 任务槽）；周卡时开始消耗
- 异常/边界：不可启动时启动键置灰+行内原因（已有训练中？不——训练也是槽项目，无"独占训练位"概念，槽满即可拒）：无在岗研究员/算力档不足/资金不足/上桌人数超限/本周卡时不足/任务槽满——六因各显（`model_train_blocked_reason` 单一原因源）

**OP-MDL-02 训练等待段查看（进度+区间+checkpoint）**
- 入口：工作区训练项目卡
- 操作：查看：进度条（周内刻级）+ 预计结账 Wx + 进度区间（%→%）+ checkpoint 预告（50% 处）
- 即时反馈：进度刻级微动；到达 50% → 确定性 checkpoint 卡点（墙钟事件叙事：损失回滚/消融提前，零数值掉落）
- 结果：等待段有"快好了"的钩子；玩家知道训练何时完成
- 异常/边界：checkpoint 卡点为确定性事件零掷骰（models 蓝图红线）；训练时长不随随机波动（rng.task 事件壳不作用于训练时长）

**OP-MDL-03 出分仪式（n 维同屏揭晓+命名）**
- 入口：周结训练完成 → 结算序列 → L2 金框头条（首次出分=署名仪式版式）
- 操作：命名框（首次强制参与感，后续可"交给命运"默认名池轮转）→ 确认
- 即时反馈：n 维逐条跳动揭晓（推理→知识→对话→速度→成本，每跳 0.2s）+ 总分同屏 + 峰值分数显示；破纪录 → 追加"破纪录"L2 金框（先出分后破纪录串行）
- 结果：模型入模型库；SOTA 榜更新（严格大于/平局归霸主）；若被竞对反超 → 周报惩罚行
- 异常/边界：命名被拒（敏感词/超长）→ 弹层不关闭可重输；跳过=默认名池确定性轮转；平庸模型（未上榜）零惩罚（失败不惩罚，onboarding 同源）

**OP-MDL-04 模型库查看（作品墙）**
- 入口：z1（`PanelId.MODEL_LIBRARY`）
- 操作：翻阅：每卡=命名/n 维画像（雷达/条形）/峰值分数/基座/训练曲线/部署状态
- 即时反馈：行展开 → 画像图 + 曲线
- 结果：单局内收藏完整谱系（P2 模型家族树）
- 异常/边界：空库 → 空态"还没有模型，发起第一次训练"（`model_library_empty`）

**OP-MDL-05 部署/授权（成品变现，economy 联动）**
- 入口：模型库成品卡 → "部署"（定价预览按 n 维画像）/"授权"（公开权重/商业授权二选一）
- 操作：部署确认 → 占部署位（单在线位）→ 常量收入周结入账；授权选择 → 即时入账（影响力 or 资金）
- 即时反馈：上线行出现（版本名+累计收支）；授权入账跳动
- 结果：产品化收入流建立；被竞对反超 → 收入 ×~0.85 且衰减加深（economy/rivals 同源）
- 异常/边界：无成品/部署位占用 → 置灰+原因（economy 键）；授权后模型锁档（禁双吃，economy 开放问题 1）

**OP-MDL-06 迭代/微调（P2 独立立项）**
- 入口：模型库成品卡 → "迭代"（同基座二次训练，定向强化某维）
- 操作：选目标维度 → 确认（少卡时换小提升）→ 排入任务槽
- 即时反馈：迭代线入槽；完成后原模型旁"v2"标注（谱系）
- 结果：同基座微调升级线（可定向强化某一维度）；模型家族树生长
- 异常/边界：**迭代收益上限卡在饱和阈值下**（防"冲分永动机"，见 D.2 护栏）；饱和后迭代键置灰+原因（`model_iter_saturated_reason`）

### A.3 输入抽象 / A.4 竖屏横屏

共用四虚拟 Action。竖屏：基座列表单列、n 维揭晓竖排、训练行满宽；横屏：双列/横排。全部入口 ≥48px。

### A.5 [P] 试玩验收句

- [P] 第一次训练出分=想截图的时刻（总分+n 维画像同屏）（前置：首训完成 → 操作：出分 → 预期：L2 头条+5 维逐条揭晓+命名参与感）。
- [P] "我的模型叫 XX，推理强但速度慢"能说出口（n 维可读）（前置：任一成品 → 操作：读模型卡 → 预期：5 维画像一眼读出强项弱项）。
- [P] 训练等待段有"快好了"的钩子：进度区间+checkpoint 卡点（前置：训练中段 → 操作：读卡 → 预期：区间+50% 墙钟事件可预期）。
- [P] "下个模型我要补它的速度短板"有决策依据（n 维驱动迭代）（前置：看弱点维 → 操作：决策 → 预期：选人/选树/升档都有对应手段）。

- 训练项目卡：z0 工作区（类型色区分，见 ui-ux-spec 总表）；基座选择：z1（`PanelId.TRAIN_BOARD`）

### B.3 重点感知排序落实

n 维揭晓（出分瞬间）=第二视觉峰值场景：5 维逐条跳动+总分同屏=截图时刻；训练进度=第一视觉（进度条主视觉放大）；模型库 z1 可查不占主台。

### B.4 动画预算（本模块消费）

- 出分仪式：L2 金框（首次=署名仪式版式，非 L3）；破纪录：L2 金框追加（串行）；
- checkpoint 卡：L1（3s 自动收）；n 维跳动：L1；本模块不消费 L3。

### B.5 竖屏折叠 / 可达性

- 工作区永不折叠；训练行满宽；n 维揭晓=数值+条形双通道；命名输入框与键 ≥48px；软键盘弹起整体上推。

### C.3 考据纪律落实

- 叙事用微调/LoRA/蒸馏/消融（蓝图 §二6 硬规则）；**禁"70b 幻觉表述"**（不编造参数规模/榜单）；
- 基座名=虚构家族（灵犀/轻羽/长河/执笔/通感），不影射真实模型（GPT/LLaMA 等）；
- checkpoint 墙钟事件=真实训练现象（loss spike 回滚/消融实验），零数值掉落；
- 训练时长=定值不随随机波动（rng 蓝图红线：随机只做增量扰动不做时长扰动）。

### C.4 仪式文案

- 首次出分命名：`model_first_score_headline` 首个模型出分！｜ `model_first_score_body` 3 个月，从一行代码到能对话。给它一个名字，署上你的实验室。≤60 字（onboarding 同源）；
- 破纪录：`rival_record_title/body`（rivals 同源键）；
- 迭代谱系（P2）：`model_iter_done` <基座名> v2 完成，<目标维> +X。

### C.5 敏感词三层

命名框三层过滤（onboarding C.5 同源键：`name_filter_whitelist/blocklist/homophone_map`+`name_filter_reason`）。

## D. 数值规格

### D.1 数据表键名规划

- `models.json`：基座表（域/档位要求/工期/卡时/上桌上限/n 维倾向）、出分公式、饱和护栏、模型库
- 引用：`chips.json`（档位门槛/卡时）、`tech_tree.json`（基座解锁）、`staff.json`（上桌员工属性）、`papers.json`（方向/影响力加成）、`economy.json`（部署定价）、`rivals.json`（守卫带）、`texts.json`

### D.2 公式与参数（~占位 → 建议区间 → 护栏断言）

| 键名 | 含义 | 占位 | 建议区间 | 护栏断言 |

**出分公式（引用键名，代码零硬编码）：**
模型维值 = 基座画像 × 员工属性映射（上桌者均值经岗位适配与协作效率）×（1 + 树定向强化）×（1 + 芯片发挥系数[能效/稳定性维]）×（1 + 状态带乘数[±10%]）×（1 + 论文影响加成[影响维]）
score = Σ(维 × 权重)；破纪录 = score > 当前 SOTA（严格）；同分归霸主。
