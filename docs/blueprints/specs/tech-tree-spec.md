# 科技树规格（Tech Tree Spec · 四件套）

> 蓝图依据：`blueprint-tech-tree.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格 → `texts-keys.md` / `numerics-master.md`
> 全局骨架：统一任务槽 4 个；**四系统共生环**（论文→树→芯片→模型→回投）；树=解锁新决策面非纯乘子；**无排他**——所有节点可研究可升级；n 维三大来源之一=科技树定向强化。

## 0. 本模块定位

玩家视角：**迷雾里的树不是"加点"而是"开门"**——每点亮一个节点，多出一种选择（新论文选题、新基座、新档位、新赛道），而不只是分数更高；没有排他——所有节点都能点亮，选择权在"先点亮哪条路"而非"放弃哪条路"。

设计原则：解锁型节点=主力；数值型=少量关键点；降费/效率型=成本杠杆；迷雾五态+翻雾三通路；任何节点效果改动必须与出分公式/饱和线/对手守卫带做数值联标推演。

## A. 交互细节规格

### A.1 术语与结构（从零定义）

- **域**（论文域 = 树域 = 芯片域共用标签，五域）：对齐/蒸馏/记忆/工具/多模态；
- **14 节点 = 10 域节点（每域 2）+ 3 交叉节点（跨域）+ 1 他者传闻占位**（P2 扩树：他者道路为后期大目标，非 transformer 路线）；
- **迷雾五态**：hidden（不可见）→ rumored（传闻：域+一句话）→ visible（可见可研）→ researchable（研究中）→ lit（点亮）；
- **翻雾三通路**：周推进揭示（rng.insight 时机 + pity）/ 竞对论文外溢（确定性规则表）/ 交叉进度（他域 lit 联动揭示相邻域）；
- **节点效果分层**：解锁型（新论文选题/新基座/新档位/新赛道）/ 数值型（出分乘子，少量关键节点）/ 降费型（任务/训练成本下降）；
- **域特化加成**：深思=出分乘子 / 蒲公英=降复现费 / 长忆=解锁长上下文基座 / 器用=解锁工具任务线 / 通感=解锁多模态基座（域有性格，路有方向）；
- **n 维定向强化**：部分节点直接强化产物 n 维（如"推理增强"→模型推理维权重提升），与员工属性、芯片档位并列为 n 维三大来源。

### A.2 玩家操作清单

**OP-TRE-01 翻雾查看（探索感）**
- 入口：迷雾面板（z1，Dock/资源栏入口；列表+1-hop 微图+"???"行+域计数）
- 操作：无主动操作（翻雾时机=系统）；玩家翻页查看：visible/rumored 节点可看描述与解锁效果预览；hidden 节点="???" 行（仅域计数）
- 即时反馈：翻雾揭示瞬间"???"行翻转为内容（迷雾散开 0.6s）；域计数 +1 动画
- 结果：探索感成立（"???" 让我想点亮它）；保底防长期无翻雾（pity 条可见）
- 异常/边界：hidden 节点无任何信息可查（掩码视觉非置灰）；同域全部 lit → 域计数满（"已探明 2/2"）

**OP-TRE-02 节点研究（点亮）**
- 入口：迷雾面板 visible/rumored 节点行 → "研究"键
- 操作：action_primary 点研究 → 确认（显示消耗=影响力 X + 前置条件）→ 周结完成 lit
- 即时反馈：研究确认瞬间节点行状态翻"研究中·第 X 周"；lit 周结节点高亮爆发动画 + 解锁内容弹卡（"新方向已解锁：<新基座/新选题/新档位>"）
- 结果：节点 lit → 效果即时生效（解锁池刷新/乘子生效/降费生效）；迷雾新区域按翻雾规则展开
- 异常/边界：影响力不足 → 研究键置灰+原因（`tree_research_disabled_reason`="还差 X 影响力，约再跑 Y 周"）；前置未满足（域前置/交叉前置）→ 置灰+原因（`tree_prereq_reason`）；lit 节点显示"已点亮"不可再研（无排他但无重复）

**OP-TRE-03 节点升级（无排他的升级路径）**
- 入口：lit 节点行 → "升级"键（数值型/降费型节点可升，解锁型节点 1 级即满）
- 操作：action_primary 点升级 → 确认（消耗递增）→ 周结完成
- 即时反馈：升级完成节点星标 +1（★→★★→★★★）；效果数值翻新
- 结果：数值/降费效果递增；升级成本曲线递增（资源稀缺制造先后取舍）
- 异常/边界：满级 → 升级键隐藏（空态=不出现）；升级中不可再升（串行队列）

**OP-TRE-04 对照表（读表胜天）**
- 入口：迷雾面板"对照表"页签（任务×基座×域）
- 操作：翻查：哪个域开哪些选题/哪些基座要哪些节点/哪些档位由哪个节点开
- 即时反馈：行选择高亮；关联节点行闪烁提示
- 结果：点树顺序有信息支撑（读表=决策依据），无黑箱
- 异常/边界：对照表只读 L2 出数；未解锁项显示"解锁条件：<节点名>"（可读可预判）

### A.3 输入抽象 / A.4 竖屏横屏

共用四虚拟 Action；迷雾面板=列表优先（竖屏列表+横屏列表+微图侧栏）；节点行 ≥48px；对照表竖屏页签横滑。

### A.5 [P] 试玩验收句

- [P] 探索感成立："???"让我想点亮它（前置：开局看迷雾 → 操作：翻页 → 预期：hidden 行+域计数+保底条可见，有好奇心）。
- [P] 节点点亮有"开了新门"的反馈：解锁型节点 lit 瞬间，弹卡说明"新选题/新基座/新档位入池"（前置：研究完成周结 → 预期：解锁弹卡+对照表刷新）。
- [P] 点树顺序有分歧（非唯一最优解）：任意两域先后顺序各有收益理由（前置：中期 5 节点可研 → 操作：咨询攻略向玩家 → 预期：两套先后方案收益接近，无"最优解唯一"）。
- [P] 任意一侧（论文/模型/芯片）进步都让树跟着活（前置：论文完成/模型出分/升档后 → 操作：看迷雾 → 预期：域计数或 RP 累计可见变化）。

### B.3 重点感知排序落实

迷雾面板=z1 面板非主台常驻（主台不显树进度，探索感=主动打开才有）；解锁弹卡 z2 轻量 ≤3s 自动收，不占金框预算。

### B.4 动画预算（本模块消费）

- lit 爆发动画：L1（0.8s，面板内）；解锁弹卡：L2 轻量（≤3s 自动收，**非金框**）；
- 迷雾散开 0.6s：L1；本模块不消费 L3。

### B.5 竖屏折叠 / 可达性

- 迷雾面板竖屏=列表单列；1-hop 微图竖屏收进详情（列表优先不画复杂图谱——蓝图"迷雾 C 方案"=列表+微图）；
- 对比度/字号/≥48px 同全局口径；节点状态色+文字双通道。

### C.3 考据纪律落实

- 节点命名全部锚定真实研究方向（对齐 RLHF/蒸馏/长上下文/工具调用/多模态），**禁伪科学名词**；

## D. 数值规格

### D.1 数据表键名规划

- `tech_tree.json`：14 节点表（域/类型/效果/前置/成本曲线/升级）
- 引用：`papers.json`（域 RP 权重）、`models.json`（基座解锁）、`chips.json`（档位解锁）、`rng.json`（灵感 pity）、`economy.json`（降费节点效果）、`texts.json`

### D.2 公式与参数（~占位 → 建议区间 → 护栏断言）

| 键名 | 含义 | 占位 | 建议区间 | 护栏断言 |
|---|---|---|---|---|
| tree_node_total | 节点总数（P0） | 14 | 固定 14（10 域+3 交叉+1 传闻） | 每域 ≥2 可研节点（防死路，蓝图 §二3） |
| tree_domain_nodes | 每域节点 | 2 | 固定 2（P0） | 每域至少 1 解锁型（域有开门感） |

| tree_lit_effect_mult | 数值型乘子 | 单级 **+2–3%** | +2–3% | 双节点满升相对增益 ≤+18%（≈+13–15 分）；**1 浅置（W20–40 可达）+1 深置**；至少 1 个改域/基座定向强化（数值席 G9 修正：+4%/级×3 级 ≈+26.5% 独占预算成全局必点） |

| tree_upgrade_max | 节点升级上限 | 3 级 | 2–3 | 升级成本递增（资源稀缺=先后取舍来源） |

| tree_tb_budget | 树对 score 总贡献预算 | ≤30% | 20–30% | **全口径**（直接乘子+解锁能力抬升，数值席 G9 修正：只算乘子则解锁型抬升不入预算=护栏空转）→ 与出分公式/饱和线/守卫带联标（numerics-master §联标推演） |
| tree_ndim_budget | 树对 n 维总贡献预算 | ≤20% | 15–20% | 树 n 维强化 ≤ 守卫带不破线（见 numerics-master §n 维联标） |

### D.3 蓝图内部一致性对账（本模块）

- ✅ 无排他全可研（蓝图 §二3 + README 评审吸收 10）；升级=无排他的深化（资源稀缺制造先后取舍，非放弃）；
