# 论文规格（Papers Spec · 四件套）

> 蓝图依据：`blueprint-papers.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格 → `texts-keys.md` / `numerics-master.md`
> 全局骨架：统一任务槽 4 个（**论文项目是任务槽三类项目之一**）；论文/模型/芯片共用槽位队列；论文=研究方向（带域标签）；**论文 n 维画像=创新/严谨/影响/复现 4 维**；域 RP 权重入点亮燃料；四系统共生环一环。

## 0. 本模块定位

玩家视角：**论文不是"刷声望的任务"，而是我的研究方向**——复现哪篇、深耕哪个领域，决定我实验室的"学术画像"；论文有谱系，我的工作有出处、有影响、有传承。

设计原则：任务=可选的论文主题（方向选择=策略表达）；论文与科技树/模型/芯片你中有我、我中有你；所有论文效果走确定性或已登记随机域（零新随机源）；任何"域 RP 权重"类设计必须先过数值推演（防"最优解唯一"伪决策重演）。

## A. 交互细节规格

### A.1 结构定义（从零）

- **项目三类共用任务槽**：论文项目（本模块）/ 模型训练项目（models-spec）/ 算力项目（chips-spec）——统一任务槽 4 个；
- **论文项目 = 复现 / 研究 / 课题 三型**：
  - 复现（repro）：接"复现某论文"任务 → RP+资金，n 维偏"复现性/严谨"；
  - 研究（research）：自选方向原创研究 → RP+影响力更高，n 维偏"创新/影响"；
  - 课题（contract）：横向课题外包 → 资金高 RP 低，n 维偏"影响"（实用）；
- **域标签**：对齐/蒸馏/记忆/工具/多模态（= 树域，选题池随树点亮扩展：**树开哪些域，论文就能选哪些方向**）；
- **n 维画像（论文核心感知）**：创新/严谨/影响/复现 4 维（0–100），加权合成单值论文质量分；
- **谱系**：已发论文入"我的论文列表"（标题/领域/影响力/引用了谁/n 维画像）；竞对论文也入谱（"他引用了我的结果"叙事，P2 引用网络）。

### A.2 玩家操作清单

**OP-PAP-01 选题接单（方向选择=策略表达）**
- 入口：任务槽空位 → "接单" → 选题池（z1，按域分组，每域列出可选题）
- 操作：浏览：选题卡=标题+域标签+预判行（工期/报酬/RP/质量倾向"创新高·复现低"）；action_primary 确认 → 排入空任务槽
- 即时反馈：选题卡按下 → 入槽动画 + 槽位进度条启动（"预计结账 Wx"）
- 结果：论文项目开跑；占用 1 任务槽（≤4 上限）
- 异常/边界：槽满 → 接单入口置灰+原因（`paper_slot_full_reason`="任务槽已满，先完成或换人"）；选题池空（域未解锁）→ 空态文案"点亮科技树解锁新方向"（`paper_pool_empty_hint`）；选题未满足前置（需某节点）→ 置灰+原因

**OP-PAP-02 论文执行中查看（n 维预览）**
- 入口：工作区论文项目卡
- 操作：查看：进度条（周内刻级）+ 预计结账 Wx + n 维预览（当前员工配置下各维区间）
- 即时反馈：进度刻级微动；n 维预览随员工状态带浮动（"严谨 72–78"区间）
- 结果：玩家可预判论文质量走向（"这篇创新高但复现性差"在完成前就可读）
- 异常/边界：无预览数据（未派员工）→ 显"--"不显 0（空态不 NaN）

**OP-PAP-03 论文完成揭晓（n 维逐条跳动）**
- 入口：周结时论文项目完成 → 结算序列
- 操作：无（自动）；玩家点"收下"
- 即时反馈：n 维逐条跳动揭晓（创新 → 严谨 → 影响 → 复现，每跳 0.2s）+ 合成质量分 + RP/影响力/资金入账跳动
- 结果：论文入谱（我的论文列表 +1）；域 RP 累计（点亮树燃料）；若为高质量论文 → 破纪录式 L2 金框（"论文被顶会接收"）
- 异常/边界：被拒稿（低质量阈值下）→ 不惩罚（退稿=正常学术），入谱标注"在投/被拒"；同周多篇完成 → 逐篇串行揭晓

**OP-PAP-04 谱系查看（学术简历）**
- 入口：z1 论文列表（`PanelId.PAPER_ARCHIVE`）
- 操作：翻阅：每篇=标题/域/影响力/n 维画像/引用了谁（P2：谁引用了我）
- 即时反馈：行选择展开 → 雷达/条形图 + 谱系连线
- 结果：单局内回看"我从复现论文走到定义方向"
- 异常/边界：空列表 → 空态"还没有论文，接一单开始"（`paper_archive_empty`）

**OP-PAP-05 对照表（读表胜天，任务×员工×域）**
- 入口：任务板"对照表"页签
- 操作：查：哪类选题适配哪个岗位/哪个域开哪些题（与树对照表同源）
- 即时反馈：行选择高亮 + 推荐标签（"这活儿谁最对口"）
- 结果：选题与派人有信息支撑
- 异常/边界：只读 L2 出数；未解锁选题显示解锁条件

### A.3 输入抽象 / A.4 竖屏横屏

共用四虚拟 Action。竖屏：选题池单列按域分组；n 维揭晓竖排跳动；横屏：选题池双列/揭晓横排。触控 ≥48px。

### A.5 [P] 试玩验收句

- [P] 任务能讲出"我在复现什么"（前置：任一论文项目 → 操作：读卡/详情 → 预期：标题+域标签+复现对象清晰，非"刷任务"感）。
- [P] 选择研究方向有真实取舍：域 RP 权重不唯一最优（前置：两域选题同时可接 → 操作：咨询 → 预期：专精 vs 多域各有收益理由，无教科书唯一解）。
- [P] 我的论文列表像"学术简历"且每篇有 n 维画像（"这篇是复现性强的稳稿"）（前置：≥3 篇已发 → 操作：开谱系 → 预期：每篇 4 维画像可读可比较）。
- [P] 点亮新树节点后论文池确实"开了新方向"（前置：树解锁型节点 lit → 操作：开选题池 → 预期：对应域新选题入池）。

### B.3 重点感知排序落实

n 维揭晓=第二视觉核心场景之一（论文出分瞬间逐条跳动，同模型出分/芯片升档）；完成前项目卡 n 维预览=任务进度卡内嵌（第一视觉内）；谱系=z1 可查不占主台。

### B.4 动画预算（本模块消费）

- n 维揭晓：L1（逐条 0.2s，≤1.2s）；高质量接收：L2 金框（预算内）；
- 入槽/顶入动画：L1；本模块不消费 L3。

### B.5 竖屏折叠 / 可达性

- 工作区永不折叠；论文卡竖屏纵向压缩、进度条满宽；n 维条形=数值标签+条形双通道（色盲友好）；字号/对比度/≥48px 全局口径。

### C.3 考据纪律落实

- 全部选题锚定 2022 年真实可复现方向（LoRA 对齐/蒸馏/长上下文/工具调用/图文对比），**禁"灵光一闪"式泛化**；
- 消融全绿/验收尾款/权重流出叙事=真实学术-工程动作（消融实验/项目验收/权重开源），非装饰性文案；
- 被拒稿=正常学术事件（零惩罚叙事，不羞辱玩家）；
- 论文完成时长与 n 维画像不与墙钟耦合（周数=唯一时间单位，time-spec 同源）。

### C.4 仪式文案

- 顶会接收：`paper_accept_headline/body`（L2 金框）；首次论文完成：`paper_first_done` 第一篇论文入库！｜ 正文：`paper_first_done_body` 学术编年史第一页。接下来，选一个方向深耕。≤60 字。

### C.5 敏感词三层

论文标题=预设选题池（无自由输入，零敏感词风险）；如需玩家自拟标题（P2 研究型），走三层（onboarding C.5 同源键）。

## D. 数值规格

### D.1 数据表键名规划

- `papers.json`：选题池（三型×五域）、n 维画像参数、RP/收入/影响力、谱系
- 引用：`tech_tree.json`（域 RP 权重/选题池解锁）、`staff.json`（员工属性→n 维映射）、`models.json`（论文影响力→模型加成）、`chips.json`（实验卡时消耗）、`economy.json`（课题收入）、`rng.json`（rng.task 事件壳）、`texts.json`

### D.2 公式与参数（~占位 → 建议区间 → 护栏断言）

| 键名 | 含义 | 占位 | 建议区间 | 护栏断言 |
|---|---|---|---|---|
| paper_slot_shared | 槽位共享 | 统一任务槽 4 | 固定 4 | 论文/模型/算力三类共用，互斥占用（≤4 上限） |
| paper_ndim_set | n 维维度集 | 创新/严谨/影响/复现 | 固定 4 维 | 与员工属性×树×芯片三源映射（numerics-master §n 维） |
| paper_ndim_weight | 权重公开 | 创新 0.3/严谨 0.3/影响 0.2/复现 0.2 | 表驱动 | 权重公开可查（无黑箱）；合成分=加权和 |
| paper_score_formula | 质量分合成 | Σ(维×权) | 0–100 | 与模型/芯片 score 同构（统一 n 维合成公式） |
| paper_repro_reward | 复现 RP 产出 | 由域权重定 | 见下 | 主域 1.0/副域 0.5–0.7（防唯一解） |
| paper_rp_weight_single | 单域专精权重 | 1.0 | 固定 | 多域混合期望收益 vs 单域专精 推演见 numerics-master §论文防伪决策 |
| paper_rp_multi | 多域混合 | 0.5–0.7/篇 | 表驱动 | 万次模拟：多域 vs 单域期望收益差 <5%（非唯一最优） |
| paper_duration | 工期 | 复现 2–3 周/研究 4–6 周/课题 3–4 周 | 表驱动 | 与员工协作缩短联动（staff-spec）；≤ 单任务槽周期上限 |
| paper_income | 资金产出 | 课题 > 复现 > 研究 | 表驱动 | 研究=影响力高资金低（方向=取舍）；课题=资金高 RP 低 |
| paper_influence | 影响力产出 | 研究 > 复现 ≥ 课题 | 表驱动 | 供给台账计数（economy-spec 同源） |
| paper_quality_drivers | n 维来源权重 | 员工 50%×树 25%×选题 25% | 推演收口 | 见 numerics-master §n 维三大来源分配 |
| paper_staff_ndim_map | 员工属性→n 维映射 | 理论→创新/沟通→影响/工程+数据→严谨+复现 | 表驱动 | 见 numerics-master §n 维映射表 |
| paper_accept_threshold | 顶会接收阈值 | 质量分 ≥85 | 80–88 | 接收=影响力大脉冲（L2 金框）；频率护栏：单局接收 ≤6 次（防通胀） |
| paper_ndim_guard | n 维不破守卫带 | 论文质量分不进 SOTA 榜 | 固定 | 论文 score 不与模型 score 同榜（防两榜打架） |
| paper_ablation_bonus | 消融全绿奖励 | 严谨维 +5 | +3–+6 | 确定性奖励（零新 RNG） |
| paper_exp_card_hours | 论文实验卡时消耗 | 1–4 卡时/周 | 按型表 | 与 chips 周预算共用（算力稀缺感） |
| paper_to_model_bonus | 影响力→模型加成 | 论文影响维 → 模型知识/推理加成 | 见 numerics-master | 共生环换算（蓝图开放问题 4 收口） |

**n 维来源分配（三大来源=员工×树×芯片，论文侧）：**
论文 n 维 = 选题基础（型+域）25% × 员工属性映射（上桌者属性经岗位适配）50% × 树定向强化（"复现高效"节点→复现维加分等）25%；方差来源=员工状态带（≤±10%）+ rng.task 事件壳（≤±10% 结算），净效果期望 ≈0。

### D.3 蓝图内部一致性对账（本模块）
