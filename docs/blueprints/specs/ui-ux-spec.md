# UI·UX 总规格（UI/UX Spec · 四件套）

> 蓝图依据：`blueprint-ui-ux.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格（总表）→ 各模块规格 → `texts-keys.md` / `numerics-master.md`
> 本文件 = 第 11 模块四件套 **且** 全游戏 UI·UX 总规格：主台/Dock/弹窗/主题/状态-视觉映射总表/动画预算总表。
> 全局骨架：统一任务槽 4 个（论文/模型/算力三类项目共槽）；重点感知排序=**任务进度 > 属性与产物 n 维评分变化 > 资源与周报 > 竞对**；竞对不常驻主界面。

## 0. 本模块定位

玩家视角：**一眼看懂实验室在发生什么**——任务进度在推进（最显眼）、一切"数值在涨"都可见（次显眼）：员工属性变化、论文/模型/芯片的 n 维质量评分变化、钱在进出；对手不占主界面，只在关键时刻现身；每个操作 0.5 秒内有反馈；竖屏不挤、横屏不空；动画有预算，仪式有排面。

## A. 交互细节规格

### A.1 主台信息架构（四主区）

```
┌───────────────────────────────────────────────┐
│ 目标卡带（引导期/阶段卡）· 可选收折            │  ← 顶部
├───────────────────────────┬───────────────────┤
│ 工作区（永不折叠）        │ 员工区             │
│ · 任务槽 ×4（三类项目卡： │ 实体卡（横滑/网格）│
│   论文/训练/算力，进度条  │ 名/状态/在岗/协作  │
│   主视觉放大+预计结账 Wx）│ 属性变化动画       │
│ · 上线行（部署版本）      │ 状态带色标         │
│ · 接单/训练轻键           │                    │
├───────────────────────────┴───────────────────┤
│ 资源栏：现金 ¥X · 影响力 X · 卡时 23/32       │  ← 底部
│ 副行：净流入预告 ~±¥X（可展开收支结构）        │
│ 竞对轻量入口（右上，无数字无红点）             │
└───────────────────────────────────────────────┘
 Dock 三键 [任务板] [科技树] [暂停]（冻结，增键=变更控制）
```

- 工作区=第一视觉区（任务进度=进度条主视觉放大）；员工区=第二视觉区（数值在涨动画）；资源栏=第三视觉（刻级跳动）；竞对入口=第四视觉（右上角小图标）；
- 竖屏：工作区在上（永不折叠）、员工区折为横滑行、资源栏单行折叠副行；横屏：工作区左宽栏+员工区右窄栏。

### A.3 玩家操作清单（全局交互链）

**OP-UX-01 任务板操作（接单/训练/算力三页签）**
- 入口：Dock"任务板"或工作区"接单/训练"轻键 → z1 TASK_BOARD
- 操作：页签切换：选题（论文）→ 基座（训练）→ 算力项目（P2）→ 对照表；行选 → 确认入槽（空槽）
- 即时反馈：入槽动画 + 工作区槽卡即时出现（0.5s 内）
- 结果：三类项目共用槽位队列（≤4）
- 异常/边界：槽满接单/启动被拒=行内原因（各模块单一原因源键）；行禁用=置灰+原因可查

**OP-UX-02 数值在涨感知（第二视觉核心）**
- 入口：无（自动播放）
- 操作：无；观看：员工属性升级闪烁/状态带色过渡/论文出分 n 维跳动/模型出分 n 维跳动+总分/芯片升档画像揭晓/现金出入跳动
- 即时反馈：全部 L1 轻量动画（0.2–0.6s）；出分揭晓逐条跳动
- 结果："数值在涨"=核心感官刺激（变强可见）
- 异常/边界：动画预算超支 → 队列截断（保留文本跳动丢弃装饰动画）；低性能模式（设置内）→ 关闭装饰动画只留文本

**OP-UX-03 周报双挂载（自动弹 z2/重看 z1）**
- 入口：自动：显著变化周 z2 自动弹；手动：资源栏周报入口（平淡周=灰点）
- 操作：自动周报"收下"关闭；灰点点一次本周消失；归档重看=同构渲染
- 即时反馈：自动弹动画；显著行瞬时高亮
- 结果：周报=账本对账+事件+竞对+仪式的唯一收口
- 异常/边界：4x 下不弹（灰点累积）；平淡周无数字无色无音效

**OP-UX-04 竞对轻量入口（查得到不压人）**
- 入口：主台右上角小图标 → z1 SOTA 榜/对决曲线（RIVAL_CURVE 通道）
- 操作：点开查看：名次/差距/曲线/预警/宿敌档案
- 即时反馈：展开动画；无红点无数字常显
- 结果：关键时刻（发版/反超/破纪录/周报）自动现身；平时查得到但不压着人
- 异常/边界：分数 <10 只显档位标签（`ui_score_grade_badge` 分级：起步档·榜外/新星档/中坚档/第一梯队/登顶档），不显裸数字；≥10 显真值（周报恒显）

**OP-UX-05 命名/输入（三层过滤）**
- 入口：模型命名框/实验室名开局命名
- 操作：输入 ≤12 字 → 确认（或"交给命运"默认池）
- 即时反馈：被拒（敏感词/超长/非法字符）→ 弹层不关闭可重输+原因句
- 结果：名字写入模型库/SOTA 榜/署名行
- 异常/边界：三层过滤（onboarding C.5 同源键）；输入框 ≥48px；软键盘上推

### A.4 输入抽象

四虚拟 Action（onboarding A.2 同源）：action_primary / action_secondary / action_pause / 方向键=面板焦点导航。主台四区之间不做焦点跳转（触屏优先）；方向键只在 z1/z2 面板内移动焦点；焦点态高亮=描边+缩放双通道。

### A.5 四态定义（总表）

| 态 | 定义 | 视觉/文案 |
|---|---|---|
| 空态 | 无数据/无内容 | 空态文案（`*_empty` 键各模块）；不显示"—"假数据（首周未出分整行不渲染） |
| 禁用态 | 条件不满足 | 置灰+原因句可查（单一原因源键）；禁用≠隐藏（拒绝分支可见） |
| 加载态 | 数据就绪中 | 骨架屏 ≤0.5s；超时走错误态 |
| 错误态 | 自检失败 | 兜底文案（`ui_error_fallback`）+error 上报；对玩家零打扰、世界不崩 |

### A.6 触屏与竖屏/横屏行为差异总表

| 场景 | 竖屏（375×667） | 横屏（844×390） |
|---|---|---|
| 主台布局 | 工作区上（永不折叠）+员工区横滑行+资源栏副行折叠 | 工作区左宽栏+员工区右窄栏+资源栏横排 |
| 任务槽卡 | 纵向压缩、进度条满宽 | 卡并排、进度条标准宽 |
| 员工卡 | 单行卡（名+状态+在岗），≥48px | 网格 2–3 列实体卡 |
| 目标卡带 | 6 点横排+单行句（顶部） | 左上角卡片（可展开） |
| 面板弹层 | 满宽纵排、可滚动 | 居中自适应 |
| 决策卡 | 满宽纵排、选项 ≥48px | 居中、双键并排 |
| 曲线（对决/现金流） | 上下布局（图上文下）可滚动 | 左右布局 |
| toast | 顶部横条满宽 | 右上角 |
| 命名框 | 满宽纵排+软键盘上推 | 居中不遮资源栏 |
| Dock | 三键均分底栏（≥48px） | 右下角三键 |

触屏纪律：可点元素 ≥48px（灰点例外 ≥24px 触区）；进度条非交互（只读可视化）；竖屏工作区永不折叠（DR-009/015）。

### A.7 [P] 试玩验收句

- [P] 10 秒内看懂主台在发生什么：第一眼=任务在推进（进度条主视觉）+人在干活（员工区状态）（前置：任意运行周 → 操作：扫一眼 → 预期：任务进度第一眼可读）。
- [P] 指派 ≤2 击；竖屏不溢出不遮蔽；对手信息"查得到但不压着人"（三段式）。
- [P] 出分瞬间 n 维逐条揭晓=想截图的时刻（前置：模型出分 → 预期：L2 头条+逐条跳动+总分同屏）。
- [P] 平淡周不被弹窗打扰；濒死时同屏看到自救入口（前置：现金<警告线 → 预期：预警横幅+救济三键同屏）。

**动效规范**：位移/透明度 120–240ms；数值跳动 200ms；金框 800ms 入场；禁用慢速大位移（低性能模式全关装饰）。

### B.3 重点感知排序落实（蓝图 §二1–4 收口）

1. **任务进度=第一视觉**：进度条主视觉放大（12px 高、卡底横贯）；周内刻级进度+预计结账 Wx+完成瞬间弹跳；
2. **属性与产物 n 维评分变化=第二视觉**：员工升级闪烁/状态带过渡/论文·模型出分 n 维逐条跳动/芯片画像揭晓；n 维变化用轻量角标提示+详情页展开（蓝图开放问题 4 收口：不全常显防挤占第一视觉）；
3. **资源与周报=第三视觉**：资源栏刻级跳动+周报收敛；
4. **竞对=第四视觉**：轻量入口无红点；关键时刻显现/可查（README 评审吸收 8）。

**L2 金框并发优先级（蓝图开放问题 2 收口）**：破纪录 > 被反超 > 顶会接收 > 季度大赏 > 首出分命名 > 融资到账 > 满树（同帧串行，各 ≤1.5s；晋升/终局 L3 与金框不同帧）。样式区分度（onboarding 开放问题 1 收口）：署名仪式版式（首出分，含署名行）/数字脉冲版式（破纪录，大数字）/授勋版式（大赏，绶带图形）。

### B.5 竖屏折叠 / 可达性

- **竖屏折叠心智权重倒序**（蓝图 §二8）：资源栏副行→员工区行高→目标卡带→工作区**永不折叠**；
- 对比度：正文 ≥4.5:1（ink2）；弱权重 ink3 只用于大字号；
- 色盲友好：全部状态=色+文本/图形双通道（红绿灯+文字、状态带+字样、类型色+图标）；
- 字号：正文 ≥14sp；数字 tabular-nums；可点 ≥48px；
- 动效：尊重系统"减少动态"设置（装饰动画全关）。
