# 经济规格（Economy Spec · 四件套）

> 蓝图依据：`blueprint-economy.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格 → `texts-keys.md` / `numerics-master.md`
> 全局骨架：统一任务槽 4 个；资源三件 cash / influence / card_hours_week；**声望/名气/影响力三词合一=单一资源 influence**（蓝图开放问题 2 收口：防两套声望曲线打架；文案统一"影响力"，引导期人话可称"声望"但键名唯一）。

## 0. 本模块定位

玩家视角：**钱是真实的压力也是真实的回报**——会真切地"穷过"，但每次危机都有可见的选项（借/卖/接活/降本），不会毫无预兆地死；我做的模型能变成钱（不只是排名），收入结构随阶段进化（劳务→产品→资本）。

设计原则：会穷、能自救、能变现；收支永远可对账（因果可见）；救济=抉择不是惩罚；产品化是长线主线。

## A. 交互细节规格

### A.1 玩家操作清单

**OP-ECO-01 收支查看（对账闭合）**
- 入口：资源栏现金位 → action_primary 点开收支结构（z1 内嵌展开，不新增面板）
- 操作：展开/收起明细行（工资 -¥X / 运维 -¥Y / 任务收入 +¥A / 部署收入 +¥B / 贷款还款 -¥C …= 净 +¥Z）
- 即时反馈：行展开动画（0.3s）；"下周净流入 ~±¥X"副行常显（含负数态，文本通道）
- 结果：任何时刻可说出"这周亏/赚多少、还能撑几周"
- 异常/边界：现金流为负仍常显（不靠颜色单通道）；无预测数据时显示"—"不显示 0

**OP-ECO-02 危机救济（借/卖/接活三件套）**
- 入口：现金 < 警告线时预警横幅常显"本周亏 X，还能撑 X 周"+ 救济入口同屏亮起（贷款/出售/私活三键）
- 操作：任选一键：
  - 贷款（z2 决策卡）：额度/宽限/分期/利息全公开 → 确认借款
  - 设备出售（z1）：当前芯片/闲置设备列表 + 折价回收价 → 确认出售
  - 接私活（z1）：限次+冷却+收入预览 → 确认接单（占 1 任务槽！）
- 即时反馈：现金到账跳动动画；预警横幅随现金恢复自动消失
- 结果：见 D.2 参数；每项救济都有可见代价
- 异常/边界：无设备可卖 → 出售键置灰+原因（`eco_sell_disabled_reason`="没有可出售的设备"）；私活已达限次/冷却中 → 置灰+原因（`eco_job_disabled_reason`）；贷款未还清再借 → 需先还清（`eco_loan_pending_reason`）

**OP-ECO-03 模型部署（产品化主线，见 models-spec 联动）**
- 入口：模型库（z1）→ 成品卡 → "部署"键
- 操作：部署（占部署位 1）→ 定价预览（按 n 维画像）→ 确认；或"授权二选一"：公开权重（+影响力）/ 商业授权（+资金）
- 即时反馈：上线键按下 → 工作区上线行出现（版本名+累计收支）；授权选择后即时入账
- 结果：常量收入每周入账；被竞对反超 → 收入 ×~0.85 且衰减加深（周报一行"被反超，收入下调"）
- 异常/边界：无可上线版本 → 上线键置灰+原因（`eco_deploy_no_release_reason`）；部署位占用 → 提示先下线当前（`eco_deploy_slot_occupied_reason`）

**OP-ECO-04 名气杠杆（影响力出口）**
- 入口：资源栏影响力位 → "市场推广"（z1）
- 操作：消耗影响力 N → 获得市场系数 M 增益（持续 X 周）
- 即时反馈：影响力数字下降跳动；资源栏显示市场系数增益角标（剩 X 周）
- 结果：部署/授权收入 ×（1+M）；与融资/门票共用一口（防三口互挤，见 D.3）
- 异常/边界：影响力不足 → 置灰+原因（`eco_market_disabled_reason`="还差 X 影响力"）；增益存续中重复点 → 刷新持续周数（可叠加时长不叠乘数）

**OP-ECO-05 融资/IPO（P2，资本阶段）**
- 入口：独角兽阶段触发融资 offer（z2 决策卡：融资额/稀释/到期偿还）；上市阶段 IPO 按钮（终局仪式）
- 操作：融资：接受/婉拒二选一；IPO：确认上市 → L3 终局动画
- 即时反馈：融资到账大额跳动；稀释率常显于终局收益预览
- 结果：融资=一次性资本+稀释（终局收益 ×(1-稀释)）；IPO=终局
- 异常/边界：融资 offer 有窗口（过期婉拒）；婉拒总可选；IPO 需满足上市条件（见 D.2）否则置灰+原因（`eco_ipo_disabled_reason`）

### A.2 输入抽象

共用四虚拟 Action；经济模块无新输入。

### A.3 四态定义（经济模块）

| 态 | 定义 | 视觉/文案 |
|---|---|---|
| 空态 | 无部署成品/无设备可卖/无救济需求 | 对应入口不出现或置灰（空态=入口不出现，禁用=入口在但不可点）；收支明细无数据行显示"—" |
| 禁用态 | 救济不可用/部署无可上/影响力不足 | 入口置灰+原因句（键名见 A.1） |

### A.5 [P] 试玩验收句

- [P] 玩家随时能说出"这周亏/赚多少、还能撑几周"（前置：任意周 → 操作：扫资源栏+点收支 → 预期：净流入预告+预警线可见；代理指标：≤5s）。
- [P] 濒死盘活看得见：贷款救活一局并付出代价（前置：现金 < 警告线 → 操作：借款 → 预期：现金跳动+还款分期进周报；无"白嫖"感）。
- [P] "我训的模型开始赚钱"有体感（前置：部署上线 → 操作：挂机 2 周 → 预期：周报 deploy 收支行增长，工作区上线行累计收支可见）。
- [P] 救济不能无限续命：摆烂还是会死（前置：持续赤字 → 操作：不改善只救济 → 预期：私活限次耗尽/贷款额度见底后破产到来）。

## B. UI·UX 规格

### B.1 呈现载体与层级

- 资源栏：z0 常显（现金/影响力/卡时三主资源；副行净流入预告）；市场系数角标 z0
- 预警横幅：z0 常显（现金 < 警告线期间）；救济入口同屏

### B.3 重点感知排序落实

资源与周报=第三视觉（任务进度第一、n 维评分第二）：资源栏刻级跳动（入/出）、预警横幅、市场系数角标全部 L1；不抢工作区视觉。

### B.4 动画预算（本模块消费）

- IPO/终局：L3 全屏（一局 ≤3 次预算内：两次晋升+终局）；
- 融资到账：L2 金框头条（"融资到账 ¥X"）；
- 其余（现金跳动/预警横幅/市场角标）：L1；
- 破产结算：L2 层级收尾（不占 L3）。

### B.5 竖屏折叠 / 可达性

- 资源栏副行=第一折叠位（DR-009/015 口径：工作区永不折叠）；现金流负值文本通道（不靠颜色）；
- 数字等宽字形对齐；预警横幅对比度 ≥4.5:1；救济键 ≥48px。

### C.3 考据纪律落实

- 贷款=宽限+分期+利息+提前还清减息（防剥削，蓝图 §二3）；文案用"过桥资金"语境不美化高息；
- 破产判定带负债（防贷款套现：贷款到账即负资产绑定，破产结算计入）；
- 部署收入=API 调用费叙事（n 维画像定价：推理/速度/成本强者价高），不用"卖模型拷贝"式反常识表述；
- 授权"公开权重"叙事与蒲公英域权重流出同一考据锚（weight decay/开源权重），边界见开放问题 1。

### C.4 仪式文案（融资/破产）

- 融资到账：`eco_financing_landed` 融资到账 ¥X（稀释 Y%）｜ 正文：`eco_financing_body` 钱到账了。代价写在合同里：终局收益 ×(1-Y%)。≤60 字；
- 破产：`eco_bankrupt_body` 见 C.1；终局页另显负债行 `eco_bankrupt_debt_line` 遗留负债：-¥X。

### C.5 敏感词三层

无自由文本输入（共用三层）；"实验室名"开局命名走三层（onboarding C.5）。

### D.2 公式与参数（~占位 → 建议区间 → 护栏断言）

| 键名 | 含义 | 占位 | 建议区间 | 护栏断言 |
|---|---|---|---|---|
| eco_startup_cash | 开局资金 | ~20 万 | 15–25 万 | ≥ 首任务报酬×10 且 ≥ 3 个月工资（onboarding 同源断言） |
| eco_salary_total_week | 周工资总额（4 人基准） | ~1.6 万 | 1.2–2.0 万 | ≤ 周收入中位 ×0.6（工资不吞光收入） |
| eco_ops_cost_week | 周运维（按档位） | T0 0 / T1 0.4 万 / T2 1.2 万 / T3 3 万 / T4 8 万 | 见 chips-spec | 运维 ≤ 该档位理论周产出 ×0.25 |
| eco_warning_ratio | 警告线=现金阈值比 | 0.3×月支出 | 0.25–0.4 倍月支出 | 0 < 警告线 < 破产线（破产线=0） |
| eco_solvency_weeks | "还能撑 X 周"公式 | 现金 ÷ 周净流出 | 上限 99 周 | 净流入为正 → 显示"盈余中"不显示负数周 |
| eco_loan_cap | 贷款额度上限 | ~15 万 | 10–20 万 | ≤ 现金警告线 ×3 且 ≤ 净资产 ×0.5（防套现额度过大） |

| eco_loan_apr | 年化利息 | ~8% | 6–10% | 提前还清减息 50%（鼓励早还） |
| eco_loan_reborrow | 还清可再借 | 是 | 恒定 | 未还清不可再借（防循环套） |
| eco_sell_back_rate | 设备折价率 | ~60% | 50–65% | ≤70%（卖卡不赚钱，救急不套利） |
| eco_job_total_limit | 私活全局次数 | 3 次/局 | 2–4 | 冷却 6 周且收入递减 ×0.8/次（摆烂会死） |
| eco_job_reward | 私活单次收入 | ~6 万 | 4–8 万 | ≤ 单任务报酬 ×1.5（救急不超主线） |
| eco_market_influence_cost | 市场系数单档消耗 | 30 影响力 | 25–40 | 增益 ×1.2 持续 8 周，可叠加时长不叠乘数 |
| eco_penalty_outclassed | 被反超收入乘数 | ×0.85 | 0.82–0.88 | 且每周再衰减 ×0.97 直到反超回（衰减加深） |
| eco_deploy_price_* | 部署基准定价 | 由模型 n 维画像算 | 见 models-spec | 推理/速度/成本强者价高；弱维打折 ≥0.5 |
| eco_stage_unlock_week | 阶段解锁周（推荐） | 劳务 0–40 / 产品 41–100 / 资本 101–156 | 阶段=行为解锁非硬周 | 阶段推进=目标卡/竞对/树共同驱动（见 numerics-master §三阶段） |
| eco_financing_amount | 融资额 | ~80 万 | 60–100 万 | 稀释 ≤20%（终局收益 ×(1-dilute)） |
| eco_ipo_condition | 上市条件 | 净资产≥X + 连续盈利 Y 周 | 见 numerics-master | IPO 成功=终局 L3 |

**核心公式（代码零硬编码，引用键名）：**
- 周净流入 = Σ收入（任务/部署/私活/融资脉冲分摊）- Σ支出（工资/运维/还款/培训）；
- 还能撑 X 周 = max(0, cash ÷ max(周净流出, ε))；
- 部署周收入 = deploy_price(模型 n 维) × (1 + 市场系数) × 反超惩罚乘数；
- 破产判定 = cash < 0 且 无可用救济（贷款未还清不可再借 + 私活限次尽 + 无设备可卖）。

### D.3 蓝图内部一致性对账（本模块）

- ✅ 三阶段收入结构（蓝图 §二1）：劳务（0–40 周）→产品（41–100 周，融资脉冲+部署萌芽）→资本（101–156 周，IPO+常量收入）；阶段解锁联动目标卡与竞对时间线（onboarding/rivals 同标）；
- ✅ 产品化主线：部署=API 常量收入、定价挂钩 n 维画像、授权二选一（蓝图 §二2 + models-spec）；被反超 ×0.85 且衰减加深（rivals-spec 同标）；
- ✅ 救济三件套：宽限+分期+利息+还清再借+提前还清减息（蓝图 §二3 防剥削）；私活=限次+冷却+递减（蓝图 §二3"收入随危机递减"落为按次 ×0.8）；破产=负债计入判定（防贷款套现）；
- ✅ 影响力=单一声望资源（蓝图开放问题 2 收口）；名气杠杆（市场系数）与融资/门票共用一口=都消耗 influence（蓝图 §二4 防三口互挤）；
- ✅ 对账纪律：唯一过账口（ledger）+周报对账闭合+"还能撑 X 周"常显（蓝图 §二5）；对账不平=冻结结算错误态（防静默错账）；
- ✅ 授权二选一供给口径：公开权重=影响力新供给源（models-spec 开放问题 1 消化：影响力供给真源=任务+事件+授权，三源全部入供给台账，见 numerics-master §供给对账）。
