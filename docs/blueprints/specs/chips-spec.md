# 芯片规格（Compute / Chips Spec · 四件套）

> 蓝图依据：`blueprint-chips.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格 → `texts-keys.md` / `numerics-master.md`
> 全局骨架：统一任务槽 4 个（**算力项目=任务槽三类项目之一**：自研芯片/算力出租/集群训练为算力型项目，P2；买卡升档=即时开支不进槽）；卡时=周预算（周结重置）；档位=供给量+解锁面双语义；四系统共生环一环（树开档位→档位撑训练→论文耗算力→模型赚买卡钱）。

## 0. 本模块定位

玩家视角：**算力是我的"设备等级"**——买卡不是填数字，而是开新门（能训更大的模型、能上更多人、能走新路线）；算力是稀缺资源，每次开训都要掂量"这周够不够烧"。

设计原则：卡时=每周预算（周结重置，防"卡池扣减"把训练卡死）；档位=供给量+解锁面双语义（买卡=打开能力门）；训练永远供得上（但供得很紧）；**n 维画像=算力/能效/成本/稳定性 4 维**。

## A. 交互细节规格

### A.1 结构定义（从零）

- **档位 T0–T4**（供给量级 8/16/32/64/128 卡时/周，蓝图"8/16/32/64 量级"）：
  - T0 学校机房（初始，8 卡时/周，零购买费）；
  - T1 入门卡×4（16，~12 万）；T2 专业卡×4（32，~40 万）；T3 服务器×4（64，~120 万）；T4 集群（128，~350 万）；
- **档位双语义**：供给量 + 启动训练门槛（基座要求最低档）；档位随经营阶段递进；
- **n 维画像（芯片核心感知）**：算力/能效/成本/稳定性 4 维（0–100），加权合成单值芯片品质分；每档画像公开可查（读表胜天）；
- **周预算纪律**：每周卡时=供给或剩余（周结重置）；超分配拒绝+"还差多少/何时够"提示（不静默卡死）；
- **算力项目（P2，任务槽三类之一）**：自研芯片/租用超算二选一（长期效率 vs 一次性投入）、算力出租/共享（危机支线收入）、集群训练（多基座并行）；
- **运维**：按档位每周运维成本（economy 支出面）；
- **升档解锁面**：与科技树节点联动（树点亮某节点→对应档位开放）；**解锁面不改任务槽位**（扩槽=独立红级，算力支撑并行叙事不越权，蓝图开放问题 1）。

### A.2 玩家操作清单

**OP-CHP-01 档位购买（一次性大开支）**
- 入口：芯片面板（z1，`PanelId.CHIP_YARD`；资源栏卡时位点开）→ 档位列表
- 操作：浏览：每档卡=n 维画像（算力/能效/成本/稳定性）+价格+供给量+解锁面预览（能训哪些基座）+运维成本；确认购买
- 即时反馈：购买成功 → 资源栏卡时供给翻新（+跳动）+ 档位徽章更新 + 解锁弹卡（新基座可训）
- 结果：档位生效（下周起卡时=新档供给）；运维成本入周支出
- 异常/边界：资金不足 → 购买键置灰+原因（`chip_buy_disabled_reason`="还差 ¥X"）；树未解锁该档 → 置灰+原因（`chip_tier_locked_reason`="点亮 <节点名> 解锁此档"）；已购档位显示"已拥有"不可重复购（升级=买更高档，非叠加）

**OP-CHP-02 卡时预算查看（周预算纪律）**
- 入口：资源栏卡时位（常显"本周 23/32"）
- 操作：点开 → 使用明细（训练项目各耗 X + 论文实验耗 Y = 合计/预算）
- 即时反馈：明细展开 0.3s；预算条颜色（充足蓝/紧张黄/耗尽红，文本+色双通道）
- 结果：玩家随时能说出"我现在一周能烧多少卡时、够训什么"
- 异常/边界：超分配尝试（如同时段训练超预算）→ 拒绝+提示"还差 X 卡时，约 Y 周够"（`chip_overdraw_hint`）；周结重置=剩余不清零不累积（周预算语义）

**OP-CHP-03 开训校验（启动前检查）**
- 入口：训练启动流程（models-spec OP-MDL-01）内嵌校验
- 操作：选基座 → 系统校验：本周卡时剩余 ≥ 该训练周耗 → 通过/拒绝
- 即时反馈：通过=正常入槽；拒绝=提示"本周卡时不足：还差 X，约 Y 周够"（明确原因非静默）
- 结果：训练永远供得上（但供得很紧）
- 异常/边界：拒绝分支可见（原因句单一源）；下周预算重置后自动可重试

**OP-CHP-04 设备出售（危机救济，economy 联动）**
- 入口：现金 < 警告线 → 救济三件套之"出售设备"（economy-spec OP-ECO-02）
- 操作：选档位设备 → 显示折价回收价（×~0.6）→ 确认
- 即时反馈：现金到账；卡时供给下降（下周生效）
- 结果：救急不套利（折价率护栏）
- 异常/边界：T0 不可售（学校机房非自有）；出售后训练中项目超新预算 → 提示"当前训练将减速/需降档"（`chip_sell_downgrade_hint`，训练不中断只减速）

**OP-CHP-05 算力项目（P2，任务槽三类之一）**
- 入口：任务槽空位 → "算力项目"（P2 解锁）→ 自研芯片（长期效率，定制 n 维）/ 租用超算（一次性投入）/ 算力出租（危机收入支线）/ 集群训练（多基座并行）
- 操作：选项目 → 排入任务槽（占 1 槽）→ 完成后效果入账
- 即时反馈：项目入槽；完成后效果弹卡（自研芯片=定制档位入池/出租=周收入入账）
- 结果：算力来源随阶段演化（租借→自购→自研）；后期算力=经营战略非数值充能
- 异常/边界：自研芯片与租用超算二选一（互斥选择，选后可换但有冷却）；出租与训练争卡时（出租期间训练预算打折）

### A.3 输入抽象 / A.4 竖屏横屏

共用四虚拟 Action。竖屏：档位卡单列满宽（n 维条形竖排）；横屏：双列。全部入口 ≥48px。

### A.5 [P] 试玩验收句

- [P] 玩家能说出"我现在一周能烧多少卡时、够训什么"（前置：任意周 → 操作：看资源栏 → 预期：卡时"已用/预算"常显，点开有明细；代理指标：≤5s）。
- [P] 开训被拒绝时有明确原因（差几卡时/何时够）（前置：卡时不足尝试开训 → 预期：拒绝句含"还差 X，约 Y 周够"）。
- [P] 买卡前能看到"这档强在哪、贵在哪"（前置：芯片面板 → 操作：浏览档位 → 预期：每档 n 维画像+价格+解锁面+运维全公开）。
- [P] 升档有"开了新门"的反馈：能训新基座/上新路线（前置：升档成功 → 预期：解锁弹卡+对照表刷新）。
- [P] 玩家会为"上不上这一档"犹豫（真实经济与战略权衡）（前置：中期资金紧 → 操作：决策升档 → 预期：n 维 trade-off（能效↔成本↔稳定性）摆台面，有取舍感）。

- 资源栏副行=第一折叠位（工作区永不折叠）；卡时预算条=色+文本双通道；档位卡 n 维条形=数值标签+条形；≥48px 全局口径。

### C.3 考据纪律落实

- 档位画像锚定 2022 真实硬件语境（消费卡→专业卡→服务器→集群），**不虚构参数规格**（不写具体 TFLOPS/显存数字，用相对维值）；
- 能效↔成本↔稳定性 trade-off=真实工程权衡（费电猛/便宜爱抽风），非"灵光一闪"泛化；
- 自研芯片叙事=定制化（NPU/专用加速语义），与"租用超算"构成真实选型决策（长期效率 vs 现金流）。

### C.4 仪式文案 / C.5 敏感词

- 集群训练完成（P2）：`chip_cluster_done` 集群就绪，多基座并行开放！≤16 字；
- 无自由文本输入（敏感词三层不适用，全局共用 onboarding C.5）。

**卡时账本公式（引用键名，代码零硬编码）：**
本周可用卡时 = 档位供给（T0–T4）；消耗 = Σ训练项目周耗 + Σ论文实验耗 + 出租占用（若出租）；
拒绝条件：消耗 > 供给 → 拒绝 + "还差 (消耗-供给) 卡时，约 Y 周够"（Y = 升级下一档所需周数估算）；
周结重置：可用 = 档位供给（剩余不清零不累积）。

### D.3 蓝图内部一致性对账（本模块）

- ✅ 卡时=每周预算+周结重置（蓝图 §二3）；超分配拒绝+"还差/何时够"提示（不静默卡死）；训练时长=定值不随随机波动（rng 红线同源）；
