# 新手引导规格（Onboarding Spec · 四件套）

> 蓝图依据：`blueprint-onboarding.md` ｜ 状态：[设计定稿·待拍板]
> 读取序：README → 蓝图 → 本规格 → `texts-keys.md` / `numerics-master.md`
> 全局骨架（贯穿全部规格的硬约束）：
> - 时间：周=唯一结算点；单局 156 周（≈3 年，2022 初→2024 末），1x/2x/4x + 暂停；
> - **统一任务槽 4 个（固定，不随人数增长）**：论文项目 / 模型训练项目 / 算力项目三类共用同一槽位队列（制作人方向 2026-09-10 追加）；
> - 资源三件：资金 cash / 影响力 influence / 周卡时预算 card_hours_week；
> - 员工规模 4→8→12；竞对不常驻主界面；动画预算 L3 全屏一局 ≤3 次。

## 0. 本模块定位

玩家视角：**前 5 分钟，我亲手走完"接单→点树→排训练→出分→命名"完整首循环，出分瞬间是我能截图、想截图的高潮；我不会被教程挡住，但也不会迷路。**

首循环即教程：第一条可接的论文复现任务就是教程的第一课；第一个模型训练项目就是教程的第二课；"失败不惩罚"——第一个模型平庸但玩家学会了流程。引导只指方向，不做事无巨细；气泡随手关、关了世界照走。

与全局骨架的衔接：**首循环的"排训练"=把模型训练项目排进统一任务槽**（占 1 个槽位），与论文项目共用槽位语义——引导期就要让玩家看到"槽里能排两类活"。

## A. 交互细节规格（从零设计）

### A.1 玩家操作清单

**OP-ONB-01 首局自动开场（无操作）**
- 入口：新局开始 → 0.5s 淡入"欢迎"L2 金框头条 + 目标卡就位
- 操作：无（自动）；玩家可点"×"立即关闭头条（头条可跳过，目标卡不可关）
- 即时反馈：头条文字逐字淡入（0.8s）；目标卡从灰点亮第 1 格
- 结果：进入自由时间（1x 自动跑），世界照走
- 异常/边界：头条关闭后 10 秒内不重弹；再次进入引导手册可回看全部文案（`onb_manual_*`）

**OP-ONB-02 目标卡查看（≤2 击）**
- 入口：主台固定位目标卡（竖屏：横向 6 点进度条上方；横屏：左上角）
- 操作：action_primary 点卡 → 详情弹层（z1）；再点任意处关闭
- 即时反馈：卡片按下 0.5s 内高亮（ink 加深）+ 弹层推入动画
- 结果：详情显示"目标句 + 还差 X 周（人话） + 替代路径按钮（如有）"
- 异常/边界：目标达成瞬间卡片自动翻新为下一张（进度条点亮一格 + L2 轻头条）；无替代路径时不渲染该按钮（空态=不出现）

**OP-ONB-03 首指派（10 秒内完成）**
- 入口：员工区任一 idle 员工卡 → 气泡"谁能干这活？"锚定（`onb_bubble_assign`）→ 点卡 → 当前可派任务槽项目列表（z1 微弹层）
- 操作：action_primary 点员工 → action_primary 点目标项目 → 完成
- 即时反馈：员工卡按下→指派成功后 0.5s 内状态字样翻新"在岗：<项目名>"+ 项目卡显示员工头像角标
- 结果：员工进入项目（项目倒计时开始）；读表面板（任务×员工×基座对照表）首次自动展开一行示例
- 异常/边界：无 idle 员工或无可派项目 → 指派入口置灰 + 原因句（`onb_assign_disabled_reason`）；引导期如玩家误点"接单"接了论文任务而训练槽被占，替代路径提示（`onb_alt_training_hint`："槽位满了，先完成这篇论文或换人接活"）

**OP-ONB-04 首点树（首个可负担节点）**
- 入口：资源栏/Dock 进入迷雾面板 → 目标卡高亮对应节点行（"??? 行"闪烁 2 次）
- 操作：action_primary 点节点行 → 研究确认（研究消耗=影响力）→ 周结点亮
- 即时反馈：节点行按下→"研究中"状态翻转；点亮周结瞬间迷雾散开动画（0.6s 轻量）
- 结果：树节点 lit；若为解锁型节点 → 对应新项目/新基座进入可接池（读表面板刷新 + 目标卡提示"新方向已解锁"）
- 异常/边界：影响力不足 → 研究键置灰 + 原因（`onb_research_disabled_reason`："还差 X 影响力，约再跑 Y 周"）；目标卡主路径卡住 → 替代目标自动亮起（默认路径=接钱任务）

**OP-ONB-05 首次出分仪式（命名框=参与时刻，非可跳过）**
- 入口：模型训练项目周结完成 → L2 金框头条（**不占 L3 预算**）
- 操作：自动弹出命名框（z2，世界等待玩家）→ 输入名字（≤12 字，走敏感词三层）→ 确认（action_primary）或"交给命运"（默认名池确定性轮转）
- 即时反馈：提交后头条翻新"《<名字>》出分 62.4 ｜ 推理 71 · 知识 58 · 速度 66 · 成本 55"（n 维逐条跳动揭晓，每跳 0.2s）
- 结果：命名写入模型库；SOTA 判定播报（若破纪录 → 追加"破纪录"L2 头条）；目标卡点亮"命名"格
- 异常/边界：敏感词/超长被拒 → 弹层不关闭可重输（原因句即时显示）；跳过=确定性取默认名（`model_default_name_pool`）

**OP-ONB-06 迎战首个对手**
- 入口：时间线第 8 周竞对首发论文 → 周报头条"深巷科技发了一篇论文，迷雾有新动静"（z2 自动周报）
- 操作：无强制操作；玩家可点周报内"查看差距"（z1 对决曲线，L2 只读）
- 即时反馈：周报行瞬时高亮 + 迷雾面板对应域计数 +1
- 结果：首个守卫时刻（L1 逼近预警黄灯在距对手动作 4 周时亮一次）；目标卡翻新为"守住 SOTA / 反超"
- 异常/边界：玩家分数未上榜（<10）→ 周报不显示裸数字，只显档位标签（起步档·榜外）

### A.2 输入抽象（仅虚拟 Action）

| 虚拟 Action | 用途 | 绑定（示意，实施时由平台层映射） |
|---|---|---|
| `action_primary` | 确认/选择/指派/研究 | 触屏点按 / 手柄 A / 键盘空格或回车 |
| `action_secondary` | 取消/关闭/返回上层面板 | 触屏"返回"键 / 手柄 B / 键盘 Esc |
| `action_pause` | 暂停菜单（Dock 三键之一） | 触屏 Dock 暂停键 / 手柄菜单 / 键盘 P |
| 方向键（焦点导航） | 面板内焦点移动（z1 弹层、目标卡详情、命名框字符位） | 触屏轻扫（焦点吸附）/ 手柄十字键 / 键盘方向键 |

纪律：所有交互只写虚拟 Action，不写具体按键；触屏目标 ≥48px；焦点导航只用于面板内部，主台四主区之间不做焦点跳转（触屏优先的形态）。

### A.3 四态定义（引导模块相关）

| 态 | 定义 | 视觉/文案 |
|---|---|---|
| 空态 | 无活跃引导气泡、无未读目标卡 | 目标卡常显但进度条 0/6 置灰；无气泡弹出（静默，不占屏） |
| 禁用态 | 引导提示指向的目标当前不可执行（如无 idle 员工可指派） | 入口置灰 + 原因句可查（`onb_assign_disabled_reason`）；**禁用不等于隐藏**（拒绝分支可见） |
| 加载态 | 引导步骤的文案/对照表数据尚未就绪（理论不存在，防呆） | 若出现：骨架屏占位 ≤0.5s，超时走错误态 |
| 错误态 | 引导状态机自检失败（步骤跳号/键缺失） | 走 `onb_state_machine_error` 兜底：跳过该步不阻塞世界 + error 上报（对玩家零打扰） |

### A.5 [P] 试玩验收句

- [P] 新玩家 10 秒内完成首次指派（前置：新局开局 → 操作：点员工→点项目 → 预期：0.5s 内卡状态翻新；代理指标：≤10s）。
- [P] 首次出分时"我知道我做了什么、接下来做什么"（前置：首个训练项目结算 → 操作：命名→确认 → 预期：出分头条含 n 维揭晓 + 目标卡自动翻新指向下一步；代理指标：命名后 5s 内无停顿犹豫）。
- [P] 目标卡任意时刻可答"还差几周"（前置：任意阶段 → 操作：点目标卡 → 预期：详情含"约再跑 X 周"人话句；代理指标：≤2 击、≤5s）。
- [P] 失败不惩罚：首个模型平庸（未上榜）不弹失败语，目标卡仍指向下一步（预期感受：流程继续，无挫败文案）。

### B.1 呈现载体与层级

- 目标卡组件：z0 常显（主台顶带）；详情走 z1（PanelStack 注册 `PanelId.TARGET_CARD`）

- Dock 三键冻结（暂停/树/手册？）——按 ui-ux-spec 总表定：**Dock 三键 = 暂停 / 接单(任务槽) / 图鉴·手册**；本模块只新增"目标卡"常显组件与 `PanelId.TARGET_CARD / GUIDE_MANUAL` 两个注册项（注册表 +2，过命令落点核对）

### B.3 重点感知排序落实（引导期）

引导期排序与全局一致：**任务进度（目标卡=首循环进度）> n 维评分变化（首出分 n 维跳动）> 资源与周报 > 竞对（首对手只在周报头条现身，不常驻）**。目标卡是"任务进度"的第一载体，视觉权重 ≥ 员工区。

### B.4 动画预算（本模块消费）

- 首出分命名 = **L2 金框头条**（n 维逐条跳动 0.2s/维，总 ≤1.2s）；不占 L3 预算；
- 破纪录（若首出分即破）追加 L2 金框，**与首出分头条同帧串行**（先出分后破纪录，各 ≤1.5s）；
- 迷雾散开 = L1 轻量（0.6s）；目标卡翻新 = L1（0.5s）；
- 本模块不消费 L3。

### B.5 竖屏折叠 / 可达性

- 工作区永不折叠（DR-009/015 口径）；引导期目标卡折叠为 6 点 + 单行句；
- 对比度：正文 ink 对底 ink_bg ≥ 4.5:1；金色头条文本用深底浅字双通道（不单靠颜色）；
- 字号：正文 ≥14sp（移动端）；目标卡句 ≥16sp；所有可点元素 ≥48px；
- 色盲友好：出分头条 n 维条形"数值标签 + 条形"双通道，不单靠色相区分维度。

### C.3 考据纪律落实

- 引导文案全部锚定真实学术动作：复现、消融、评测、权重衰减；**禁用"灵光一闪/断电掉半周"式泛化或反常识表述**；
- 首循环叙事：第一个训练项目=「复现一个迷你对话模型」，微调/LoRA/蒸馏等词不在引导期出现（P1 论文深化才引入）；
- 引导期不出现 2022 年后才有的工具概念（如"智能体工作流"），世界观时间线=2022。

### C.4 仪式文案（首出分命名）

- 头条标题：`onb_first_score_headline` 首个模型出分！
- 正文：`onb_first_score_body` 3 个月，从一行代码到能对话。给它一个名字，署上你的实验室。
- 署名行：`onb_first_score_byline` 署名：<实验室名> 实验室 · <日期>
- 命名输入提示：`onb_naming_hint` 名字 ≤12 字，会写进模型库与 SOTA 榜。
- 默认名池（确定性轮转，键池）：`model_default_name_pool` = ["灵犀初号","小满","回声","候鸟","守拙","不器"]（示例，池名入 texts-keys 总表）

### C.5 敏感词三层

命名框/实验室名统一走三层（键名入 texts-keys 总表）：
1. **Unicode 白名单** `name_filter_whitelist`：中文 CJK 统一表意文字 + 拉丁字母 + 数字 + 空格 + 常用标点（-_.·）；
2. **词表** `name_filter_blocklist`：侮辱/政治敏感/广告词表（示例条目：脏话、政党领导人名、色情词、交易广告词）；
3. **防真人近音** `name_filter_homophone_map`：对白名单通过的文本做常见近音映射检测（如"习/席/近/平/泽/东"等组合近音、全拼/拼音首字母组合），命中即拒并提示 `name_filter_reason`（"这个名字不合规，换一个吧"）。

### D.3 蓝图内部一致性对账（本模块）

- ✅ 首循环=做中学：接单（论文项目）→点树（研究）→排训练（任务槽模型项目）→出分（n 维揭晓）→命名（参与时刻）→首对手（第 8 周守卫）——与 onboarding 蓝图 §二1、§四 P0 六步一致；
