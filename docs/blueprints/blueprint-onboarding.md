# 新手引导蓝图（Blueprint: Onboarding）

> 状态：[讨论稿] ｜ 阶段：P0 已具雏形，P1/P2 目标形态如下 ｜ 读取序：README → 本文件

## 一、定位

**玩家视角**：前 5 分钟，我亲手走完"接单→点树→上训练位→出分→命名"完整首循环，出分瞬间是我能截图、想截图的高潮；我不会被教程挡住，但也不会迷路。

**设计原则**：做中学（首循环即教程）> 遮罩教程；引导只指方向，不做事无巨细；失败不惩罚。

## 二、目标形态（终态）

1. **首循环仪式**：第一个模型出分 = 仪式时刻（**L2 金框头条级，不占用"一局 ≤3 次 L3 全屏"预算**——L3 仅晋升与终局），命名框非可跳过而是"参与时刻"。
2. **阶段目标链**：每阶段一张目标卡（P0 引导链泛化为三阶段目标），目标 = 该阶段第一个可达成的高潮（点出首个节点/首次出分/迎战首个对手），且带"替代目标"（主路径卡住时给出另一条可达路径）。
3. **人话翻译**：所有目标用"还差 X 周""约再跑 X 周"表述（玩家对周数有感，对抽象资源数无感）。
4. **可跳可回来**：气泡随手关、关了世界照走；失败教学一次只弹一条。（多周目豁免/往年卷暂不做，单局内引导自足。）

## 三、GDS 可复用语言

- **首个循环即教程**：GDS 开局第一个项目就是完整教程；本作教学链（复现→对齐→灵犀复现）= 同一结构。
- **失败不惩罚**：第一个模型平庸但玩家学会了流程。
- **读表胜天**：引导期把"任务×员工×基座"的对照表公开给玩家（谁能干这个活/这个模型要几个人），可预判=可针对。

## 四、阶段路径

### P0 骨架：首循环引导链
- 内容：6 步目标卡（接单+点首个可负担节点 → 攒声望 → 上训练位 → 出分 → 命名 → 迎战首个对手）；横向 6 点进度条（竖屏）；"还需 X≈再跑 X 周"人话；替代目标=默认路径。
- 判定 [P]：新玩家 10 秒内完成首次指派；首次出分时"我知道我做了什么、接下来做什么"。

### P1 深化：阶段目标链
- 内容：目标卡按三阶段（实验室/独角兽/上市）演进，每阶段目标=该阶段的心跳时刻；替代目标随阶段扩展（升档/接钱任务/扩张）；目标进度与"自由期三线"合并展示。
- 判定 [P]：任意阶段开局 30 秒内知道本阶段第一个里程碑是什么；替代路径真实可达（不是摆设）。

### P2 长线：引导内化
- 内容：引导从"教规则"转为"给方向"——阶段目标链在后期继续演化为自由目标（拍板/冲刺目标）；新手引导低频复现为可查的手册（不强制弹出）。
- 判定 [P]：单局后期打开手册能快速回忆所有机制；引导不再打扰熟练玩家。（多周目豁免/往年卷暂不做。）

## 五、系统联动

- 员工（可指派感）→ 首指派动作
- 科技树（首个可负担节点）→ 首目标
- 模型（首次出分/命名）→ 首仪式
- 竞对（首个对手）→ 首守卫
- UI/UX（目标卡组件/竖屏进度条/仪式动效）→ 呈现层

1. 首次出分仪式的 L2 金框头条具体呈现（与晋升/破纪录金框的样式区分度）——L3 全屏预算仅晋升与终局，首出分不占用（已定）；
