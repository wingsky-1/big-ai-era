## 1. 愿景与基调 [已定]

**愿景一句话**：你是 2022 年某高校 AI 实验室的博导，从复现论文起步，点亮迷雾中的 LLM 科技树，把实验室带成上市公司——"你也想做 ChatGPT"的开罗式模拟经营。圈内人玩梗，圈外人玩经营。（DR-013）

**已定基调**：

| 维度 | 决策 | 依据 |
| :--- | :--- | :--- |
| 品类 | 开罗系模拟经营（时钟推进+数值模拟），无物理/动作手感 | DR-013 前定 |
| 时间模型 | 实时流淌制（~10s=1 周，可暂停，1x/2x/4x） | DR-009 |
| 随机性 | 乙档收窄版：随机仅竞对扰动+灵感时机两处，全部周结点消费；pitch="揭示时机随机、结果成败不随机" | DR-001 |

## 2. 核心循环与节奏宪法 [已定]

> **单局目标形态（DR-031/§十二，制作人 2026-09-08 裁决）**：**v1.0 先做短单局体验**——一局 160 周 ≈ **26.7 分钟**（10s/周 @1x）；成功标准 = "一局从头玩到尾，有高潮、有收尾、想再开一局"。**长线（10h+ / 多周目继承）推迟 v2.0**。实算风险：**W54（第 9 分钟）即 99 分封顶 → 其后 106 周（单局 66% 时长）无分数成长**；三条落地：①自由期三线（霸榜周数 / 树 n/14 / 影响力存量）**提前到 W25**；②竞对重标时 **L4 标到 ~96–98 分**（与玩家封顶 99 分差 1–3 分 → 守卫张力，**禁超玩家**）；③封顶叙事「已登顶·自由期」+ 终局 summary 扩六项。

**核心循环**：周初规划（分配研究员/排任务）→ 实时流淌（进度/收支刻级跳动）→ 周结（周报时刻：收支/出分/SOTA/竞对/迷雾/事件一次结算）→ 事件应对（决策卡）→ 阶段晋升检查。（DR-007 / DR-009）

**心跳时刻**：每周一次的"周报时刻"——玩家据此做下一轮规划；出分瞬间=截图时刻，命名仪式=参与而非可跳过。（DR-002 / round3 玩家之声）

**节奏宪法**（DR-009，数值红线可随试玩反馈调、结构不改）：
- 有效决策 1–3 次/30s（峰值 ≤6）、同屏待决 ≤1、**每周必做 ≤1**；
- 真空三件套（训练等待段=研究经营窗口，不是塞事件）：①任务排队预填（完成自动顶入队首）②训练播报（进度刻级）③迷雾/阶段照常推进；连续 3 真空窗（~2 分钟）无新信息=设计违约；
- 动画三级预算：L3 全屏动画一局 ≤3 次（两次晋升+Game Over）；
- 密度一律按 1x 定义；4x=挂机加速非决策加速；
- 竖屏折叠=心智权重倒序，工作区永不折叠（DR-015）。

## 3. 三阶段与软门 [已定]

三阶段=玩法增量+经济结构差（阶段数值差异表见 §6）：

| 阶段 | 玩法增量 | gate（谓词数组+一层 any_of，禁 DSL；值 ~ 占位） | 依据 |
| :--- | :--- | :--- | :--- |
| 实验室 0–~24 周 | 复现/研究/课题、点基础树 | 影响力 ≥~50 且 累计经营收入 ≥~250k | DR-029 C-1/C-2 / DR-028 R-9 |
| 独角兽 ~25–~64 周 | 融资脉冲、扩算力、扩编（一次性扩建费 ~40–60k，DR-029 A-7） | SOTA 次数 ≥~3 且 累计经营收入 ≥~1200k | 同上 |
| 上市 ~65–160 周 | API 常量收入（deploy）、季度财报日事件卡、护城河经营 | 终局：自由期持续经营或破产 Game Over | DR-028R R-1R |

**机制规则**：
- **晋升判定仅周结点执行**（`stages.reevaluate()`，管线第 10 步）；gate 数据进 `stages.json`（enabled 占位，MVP 常开实验室期逻辑）。
- **累计经营收入口径**：一个 flags 计数器（`cum_income`），**融资/IPO 不计入**（防镜像刷感）；禁估值/股权字段（红级否决维持）。（DR-028 R-9 / DR-029 C-2）
- **机会窗口连续衰减**：晋升窗口超过 expected_p50 后，stage_depr 参数每超 ~10 周 ×0.95（下限 0.7）——替代阶梯式 ×0.7 卡点。（DR-029 C-3）
- **常数出处纪律**：`stages.json` 中 expected_p50=p50+30 的常数必须写注释注明出处（=P90 断言带 +15 的 2 倍）；"没有出处的常数都会变成祖传神秘数字"。（DR-029 C-4）
- 晋升呈现：stage_advanced 信号+晋升并入周报头条（保 L3 动画预算）；lab→独角兽=金框头条三行+"新"角标。（DR-029 C-5 / DR-020）
- **自由期三线**（霸榜周数/树已探明 n/14/影响力存量）优先级压过摆弄层——"亮 9 后缺的是目标不是手活"。计数器+差距行随 PR5/PR9b 顺手入。（DR-029 C-6）
- SG1–SG3 归属：随 PR5，不单开 PR（信号随 PR5、头条渲染随 PR9b）。（DR-029 C-7；模块文档"PR5*"待定标注由此关闭）

**边界**：gate 不满足时维持当前阶段，不回退；Game Over 时阶段冻结入终局档；融资行/API 行仅在各阶段 enabled 翻真后参与周结（schema 占位已在 v1）。

## 5. 时间与随机性 [已定]

### 5.1 时间模型与驱动分离

- 模拟层永远 tick 步进：GameClock 每刻步进，满周触发 `settle_week()`；View 层（GameLoopDriver）把 Δt 交 L0 `clock_math` 累积，满刻调 `world.tick()`。变速 1x/2x/4x=View 层系数。（DR-021 M1 / ADR-0006）
- **暂停双源**：`paused = user_paused OR blocked_by_card`（OR 合成）；set_paused 只写 user_paused；L2 忽略与 pending 冲突的 set_paused(false)。（DR-021 M1 / v1.1 B）
- **只在场才流淌**：关页/后台不可见=View 停喂 tick（零模拟层改动）；周报自动弹 z2=临时停喂。（DR-022② / DR-020）

### 5.2 周结管线 v2.1 全序（DR-007 / v1.1 D，唯一写盘点）

前置不变式：`pending_decisions` 为空（带卡不结周）。
```
1  economy.accrue_week()              # 收支（全部经 apply_delta 过账）
2  if money <= bankruptcy_line:       # Game Over 短路——判定写死在收支后
      终局档 → game_over(summary) → 跳过 3–10 直接返回
3  for e in effects_pending: apply(e) # delayed 效果在出分前消费（训练类在此触碰状态机）
4  if training.finished():            # 出分（research_eff=Σ，m=compute.tier 联动）
5     sota.submit(...)                # SOTA 严格大于/平局归霸主；命名请求 naming_request
6  rival.advance(rng.rival_jitter())  # 竞对 ±15%【RNG 域 1】+论文外溢（零 RNG 确定性规则）
7  fog.advance(week_rp, ...)          # 迷雾推进+解锁重评
8  if rng.inspiration().hit(): ...    # 灵感【RNG 域 2】
9  events.evaluate(rng.event_roll())  # 事件【RNG 域 3】→ 同周双卡顺延规则见 §11
10 stages.reevaluate()                # 阶段软门重评
11 emit week_settled(rpt) → 周界自动存（SaveSystem 唯一写入口）
```
RNG 消费点恰 3 处（grep 可验断言）：rival_jitter / inspiration / event_roll；默认名池兜底=确定性轮转不设第 4 点。插新步骤=黄级（须保 RNG 顺序稳定）。

> **步序修正（DR-031/B-2，C1 改造的硬前置）**：现实现的**任务结算在步序 2（破产短路）之后**（`game_world.gd:456–490`）→ 改占槽口径后任务收入将**在破产判定之后到账**，导致"本周有 +42k 结算仍被判破产"。**修法**：任务结算并入步序 1，或把短路判定移到任务结算之后；**同步修订 `DR-021 B3`"判定写死在收支后"的契约表述**（"收支"的定义已随 C1 改变）。

### 5.3 确定性随机（ADR-0008）

分域 counter-based RNG（`src/systems/rng/rng_stream.gd`）：root_seed+各域独立计数器入档（rng{} 开放容器，新随机域=加键零迁移）；万周模拟同 seed 双跑哈希一致进 verify.sh，万局归 nightly。（DR-001 / DR-021 M2）

### 5.4 验证入口

`simulate_weeks(n, policy, seed)`：headless 推进返回逐周报告；`AutoDecisionPolicy` 注入实现测试同帧应答零卡死。（GW2/GW3 / v1.1 B）

## 6. 经济与算力 [已定]

### 6.1 资源与过账

三资源：资金 ¥ / 算力卡时 / 影响力（**RP = 影响力同一池**；DR-031/§2.9 第 4 条：承认同一资源——**修订原"只进不出"为"可消耗（点树）"**；外部出口仍 v0.2，R4 口径诚实化）。**apply_delta(resource, amount, reason) 唯一过账口**（原子应用+resources_changed），周报对账必须闭合。（DR-021 M3 / EC2）

### 6.2 v0.1.0 双来源（DR-006；**口径收口见 DR-031/C1**）

- 课题脉冲（第三类任务，grant：~4–8 周、~30–80k/笔）+ 复现小额（~5–12k/3–5 周）+ 固定支出（工资/训练）；
- **收入口径（DR-031/C1 裁决）**：实验室期/独角兽期的经营收入**只来自占槽任务结算**（回归本条原意）；`Economy.accrue_week` 的"每周 roll 双来源脉冲"形态**退役**（不再是 v1.0 收口值）。上市期 API 常量收支行维持（DR-028R R-1R，不属本禁令）。**实算依据**：每周 roll 形态的周期望收入 63.5k（复现 8.5k + 课题 55k）→ 160 周 1016 万、gate 250k 在 W3.9 达标、破产率恒 0（V1 断言下限 0.5% 永不满足）；
- **任务池参数联标（DR-031/C3；对抗评审 B-3 + §2.9 修正）**：课题类 `income ~60k/4 周` + `rp_output ~150`；复现类 `income ~15k/3 周` + `rp_output ~100–150`；**新增固定运维支出 ~3k/周**（使 lab 期周支出 ~9k，对齐 §6.4）；gate 值 250k 与 lab 期 24 周**不动**（守 DR-028 R-9 / DR-029 C-2）。实算：**开局教学链占槽 ~7 周**（`paper_0` 3 周 + `lingxi` 4 周）→ 24 周余 17 周 ≈ 4 笔课题 → `4×60k + 8k + 12k = 260k ≥ 250k ✓`（余量 4%）；**RP 供给**：160 周单槽串行 ≈ 40 笔 × ~150 = **6000 RP** → V6 P50=7 ✓（详见纪要 §2.9）；**实现落点（#76）**：`tasks.json` 的 `rp_output` 按"单位时间供给"标定（课题 150/4 周、灵犀复现 140/4 周、纸面复现 110/3 周、基础研究 150/4 周，即 35–37.5 RP/周）→ 160 周单槽实跑 **~6000 RP** 落供给带 `[4910, 6810)`；数据表级护栏断言"单位时间供给 ∈[31,42] RP/周"保证任意任务选择都落带。
- **r 曲线管压迫（~0.75→1.05）、stage_depr 管收入衰减——职责分离**（EC4）；
- 破产线 **-200k** 单线判负；警告线 **~-30k**（预演建议，试玩定）；开局资金 **~50k**。V1 双断言：基线破 30 周率 <1%+标准扩张剧本 ∈[0.5%,8%]。（DR-027②）**注意**：V1 断言随收入形态（DR-031/C1）失效，**必须重标**。

### 6.3 算力"档位+余量"（EC5 / DR-018）

买卡=升档（m 档位=卡池规模档）；**两个概念必须并存且分键（DR-031/D-6·D-10）**：①**每周卡时供给 `~8/16/32/64`**（与 `model_bases.hours_per_week` 6/14/30 逐档差 2，训练永远供得上）；②**容量上限 `~40/80/160/320`**（`economy.json` 的 `compute_tiers.capacity`，仅作余量上限校验）。**卡时消费口径 = 每周预算**（每周结重置为供给，**不是"卡池扣减"**——若按卡池扣减，璞石全程需 60 卡时 > tier1 容量 40，训练立刻不可行）；`weekly_card_hours ≤ 每周供给` 才可开训（门槛检查+余量字段）；**超分配拒绝顺延 v0.2**（DR-018）。买卡入口（N9）与卡时消费（N10）**升 v1.0 P0**（DR-031/D2）。

### 6.4 三阶段经济差异（DR-028§四，全部 ~ 占位，PR3 复算/PR10 收口）

| 维度 | 实验室 0–~24 | 独角兽 ~25–~64 | 上市 ~65–160 |
|---|---|---|---|
| 收入占比 | 课题 ~55 + 复现 ~45 | 课题 ~45 + 复现 ~15 + 融资 ~25–40 + API ~0–20 | API ~55–70 + 课题 ~15–20 + 支线常态 |
| 脉冲量级 | 课题 ~30–80k/4–8 周 | 课题 ~60–140k/6–11 周；复现 ×0.5；融资 ≤2 次 | 课题 ~90–180k/8–14 周；复现 0；IPO ~200k 一次性 |
| 周支出 | ~9k（工资 3×~2k + **固定运维 ~3k**，DR-031/C3 新增键） | ~18k（扩编+房租 ~5k） | ~46–58k（10–14 人+运维） |
| 谷值容忍 | ~-30k | ~-80k | ~-150k |
| 玩家焦虑 | 发薪日 | 跑道 | SOTA 鲜度 |

**三阶段结构差的必要件**（DR-028R R-1R，缺一则该阶段经济数学上不成立）：独角兽期=融资脉冲收支行（三键 ~50–80k/稀释 ~12%/≤2 次）；上市期=API 常量收支行（deploy）。财报日=事件卡化（压力节律器非收入源）。估值/股权入档=红级否决维持。

**deploy**：门槛动态锚 `deploy_threshold = max(60, sota_top_score − 15)`（~）；参数带（market_base_k/share_cap/price_tiers/decay_weekly 等）v0.2 收口。（DR-028 R-4 / 纪要§三）

**基座质量乘子 q(base)**：v0.1.0 即落——璞石 ~0.55/玄冰 ~0.8/深渊 ~1.0（防"大材小用"冲榜漏洞；PR6 落表前数值席精算）。（DR-028§二）

**API 占比断言分阶段**：实验室/独角兽期 API ≤~40%；上市期 ∈[~50%, ~70%]。（DR-028§二）

### 6.5 支线危机收入（v0.2，DR-028 R-2/R-8 + 28R）

危机态=cash<警告线（静态口径，零 RNG）；v0.2 第一批=事件卡级 3 张（贷款[必带偿还：本金×~1.2/~4 周 delayed money]/设备出售/接私活）；试玩裁决后可升常驻（算力出租/企业咨询[影响力 ≥~50 门票]/开源赞助[≥~80]/私活转常驻为蓝本）。防刷四闸：谓词触发不可购买/冷却或 once/占任务槽机会成本/同类递减（stage_depr 表驱动）。标定目标：危机态三线并发 ~8–15k/周 ≥ 固定支出 ~60%。影响力门票汇率 ~1k¥/影（危机两线 0 门票=救生索不设闸）。

**边界**：融资/IPO 金额不入 cum_income（§3）；deploy 收入受被反超惩罚（×~0.85 且衰减加深）；贷款 delayed money 进 effects_pending 队列（§11 timing 通路）。
