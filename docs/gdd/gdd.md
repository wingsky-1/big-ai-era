## 愿景一句话

`[提案]` 你是 2022 年某高校 AI 实验室的博导，从复现论文起步，点亮 LLM 科技树，
把实验室带成上市公司——类开罗《游戏发展国》数值骨架 × 大 AI 时代题材。

## 已定基调（与制作人确认）

| 维度 | 决策 | 影响 |
| :--- | :--- | :--- |
| 品类 | 开罗系模拟经营（时钟推进 + 数值模拟） | 无物理/动作手感；纯逻辑模拟核心 + 仪表盘 UI |
| 时间模型 | **实时流淌制**（约 10s = 1 周，可暂停，1x/2x/4x 变速） | 实时映射只在 View 层（GameLoopDriver），模拟层永远 tick 步进 |
| 事件形态 | **实时插入式**（决策卡阻塞 / 通知 toast 分级） | EventEngine 持续评估，触发分级处理 |
| 竞对 AI | **脚本化里程碑**（时间线 + 随机扰动 ±15%） | rivals.json 时间线驱动，发版在周界触发 |
| 视角/端 | 2D，移动同步（手机 Pages 试玩一等公民） | gl_compatibility 不变；触屏三件套降级为"触屏 UI 规范" |
| 协作 | Agent 开发自验证，人类想法 + 试玩反馈 | 本脚手架工作流 |

## 核心循环（Core Loop）

`[提案]` 周初规划（分配研究员）→ 实时推进（进度/收支连续跳动）→ 周结（周报/
里程碑/竞对发版/自动存档）→ 事件应对（决策卡）→ 里程碑达成则阶段晋升。

**心跳时刻**：每周一次的"周报时刻"——研究进度、收支、竞对动态、SOTA 变化，
玩家据此做下一轮规划决策。

## 三阶段成长

| 阶段 | 玩法增量 | 晋升条件（草案，待数值化） |
| :--- | :--- | :--- |
| 实验室 | 复现论文、发论文、接课题、点基础科技树 | 影响力 + 累计资金达标 |
| 独角兽 | 融资（稀释股权）、扩算力池、自研芯片立项 | SOTA 次数 + 估值 |
| 上市公司 | 产品化 API 收入、季度财报压力、护城河经营 | 终局：市值 / SOTA 霸榜 |

## 六大系统骨架

| 系统 | 骨架职责 | 纯逻辑件（可无头单测） | 数据表 |
| :--- | :--- | :--- | :--- |
| GameClock 周引擎 | tick 推进 + 刻结/周结管线 | `GameClock` + `GameLoopDriver`(View) | - |
| 科技树 | DAG 点亮/解锁/加成（主线 LLM + agent-harness + 芯片支线） | `TechTree` | `techs.json` |
| 员工（研究员） | 属性/分配/体力士气/薪资/隐藏特质 | `Staff` + 任务调度 | `staff_templates.json` |
| 训练项目 | 选基座→分配人→N 周→评测出分→SOTA 判定 | `TrainingProject` | `benchmarks.json` / `model_bases.json` |
| 经济 | 资金/算力/影响力三资源收支 | `Economy` | `economy.json` |
| 随机事件 | 条件评估→加权抽取→效果应用（决策卡/通知分级） | `EventEngine` | `events.json` |
| 竞对 | 脚本时间线 + 进度条压迫感 | `Rival` | `rivals.json` |

**资源模型 v1**（刻意克制）：资金 ¥（工资/买卡/课题收入/融资）/ 算力卡时（训练
硬约束）/ 影响力（招人质量、估值、晋升门槛）。

**训练模型公式雏形**：能力分 = f(算法贡献, 工程贡献, 数据, 算力, 科技加成) →
各 Benchmark 得分 → SOTA 判定（vs 竞对）→ 影响力/收入。

## AppFlow / 音频 / 触屏 落位（修订版）

- **AppFlow**：BOOT → MENU → GAME；GAME 内部 = 单 Dashboard + `PanelStack`
  弹窗栈（科技树/员工/训练详情均为面板，非场景切换）。AppFlow 只管"去哪"，
  不管存档（离开 GAME 前由 GAME 内部触发自动存档）。
- **音频**：`AudioService`（autoload），总线 Master→BGM/SFX/UI；BGM 单播放器跨
  场景续播 + SFX 池 8 个；音量持久化；音频 ID 走 `data/audio.json`。
- **触屏**：~~虚拟摇杆~~（品类为点击交互，不需要）→ 改为触屏 UI 规范：
  点击目标 ≥48px、面板可达性、横竖屏适配策略，纳入 ui-ux-designer skill。
- **暂停语义分层**：全局暂停（玩家键/决策卡阻塞）= `GameClock.paused`；
  变速 = View 层 accumulator 系数；面板打开**不暂停**（保持流淌感）。

## MVP 切片 v2（第一个可玩版本）

**进**：GameClock（刻/周双结算）+ GameLoopDriver（1x/2x/4x/暂停）+ 三资源连续
收支 + 3 名研究员 + 排队任务系统（复现/研究两类任务）+ 精简科技树 15 节点 +
训练项目（出分→SOTA）+ 1 竞对（时间线 10 动作）+ 事件 8 张（3 决策卡 + 5 通知）
+ Dashboard 周报。

**明确不进**：融资/上市、芯片支线、隐藏特质、招聘市场、倒计时决策、多槽存档、成就。

## 操作/输入映射

沿用脚手架虚拟 Action（`project.godot [input]`）。本品类以点击为主：
`action_primary`（选中/确认）、`action_secondary`（取消）、`pause`（暂停菜单）；
方向键用于面板焦点导航（键盘可达性）。
