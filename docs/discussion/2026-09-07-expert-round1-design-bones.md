## 1. 六席一致点（评审确认质量高，建议打包确认）

1. **存档**：周界自动存（周结管线末尾）+ 退出/切后台存 + 手动存；单槽 UX + 文件级
   双缓冲（`tmp → 校验 → 换名 + .bak`）；全量快照（<100KB）；schema 重置 v1、删
   脚手架演示迁移（重置仅此一次，此后变更走最小迁移链——与 P5 排序表述已对齐）。
2. **周结管线顺序**：收支 → 训练出分 → SOTA 判定 → 竞对 → 存档；出分/判定只在
   周结点，刻结算只做算术累积。
3. **事件语义**：只在结算点产出；决策卡阻塞 = `GameClock.paused`，未决卡进
   `pending_decisions` 队列并入档（**入档须含事件 id + 已展示选项 + 已应用效果，
   否则与"预告=结算一致"验收打架**）；条件谓词硬编码禁 DSL；预告=结算逐项一致。
4. **toast**：非阻塞、模拟层通知队列 View 逐帧消费；同屏 ≤3、计时绑 GameClock、
   分级不单靠颜色；不入档；超限折入周报。
5. **周报**：自动弹出 + 临时暂停 + Dock 重看入口——**节奏已按评审 R3 修正，见 §2-R3**。
6. **UI 骨架**：PanelStack z 三层、常规面板互斥栈深 1、单向信号（UI 零写路径，
   grep 可验）、横屏基准 + 竖屏完整降级、触屏三规则。
7. **分层**：accumulator 数学进 L0 纯静态；GameClock + 六系统 + GameWorld 门面落
   L2 RefCounted（评审确认非过度设计：headless simulate/存档快照/UI 单向信号的
   共同支点）；GameLoopDriver / PanelStack 落 L3；TextService 走 L1 注入
   （**不新增 autoload**，红线）。
8. **模拟验证**（评审 M-1 重排）：`verify.sh` = 单次万周模拟（<5s）+ 百局降采样
   smoke；万次模拟（N≥1000 局）进 nightly；断言区间参数进 JSON。**补"每局科技
   点亮数分布"断言**（单任务槽下研究/复现/训练抢槽的节奏风险回归网）。
9. **文本体系**：texts.json 键引用单一真源 + TextService 单一入口 + 断链/死键/
   **长度断言（每键 max_len 字段）**三条单测；数值先过统一 Formatter 再进文本与 UI。
10. **风险共识**：第一个 build（仅 MENU）立刻上 Pages 真机验加载/内存；移动端
    硬杀进程丢当前周（≤10s）写入已知限制；iOS visibilitychange 可靠性真机验证。

## 2. 关键冲突裁决建议（C1–C4，均已按评审修订）

### C1 出分公式（冲突：Cobb-Douglas vs 线性 ≤3 自变量）

**裁决建议：v0.1.0 采用退化 Cobb-Douglas**——
`A = K · (1 + research_eff)^0.7 · (1 + tech_bonus)^0.3 × m(算力档)`
- 3 自变量满足切片约束；**"零返工"改口"低成本扩维"**：v0.2 扩 4 因子时 K 重锚、
  科技性价比、V-sim 断言区间须重调（已列入 v0.2 预算，评审 ①②成立）。
- **输入通路必须钉死（评审 B-1，裁决点 R1）**：(a) 推荐——`bonus_research` 唯一进
  `tech_bonus` Σ；`research_eff` = **已分配**研究员研究力均值（0 人=训练不可发起；
  1 人=单人值）；科技树 + 算力档 = 唯二成长杠杆，U40"点卡再分配"因此有意义。
  (b) 备选——bonus_research 进 research_eff、删 tech 因子：公式只剩算力档一个
  活变量，训练退化为纯时机决策，**不推荐**。
- sigmoid 映射、θ/k 进表、SOTA 严格大于、平局归霸主、仅周结判定照旧。

### C2 科技树规模与效果池（冲突：15 节点解锁型 vs 10–12 节点切薄）

**裁决建议**：接受 10–12 节点 + 列表式 UI + 混合型语义 + 四元组 schema；
**MVP 效果池（评审修正后）**：
- 实配两类：`stat_bonus`（**仅 bonus_research**，经 R1(a) 进出分公式）+
  `unlock_grant`（解锁更高课题收入档，靶子依赖 R2）；
- `bonus_influence` **不配实例**（影响力 MVP 只进不出，无消费者，评审 ②）；
- `unlock_base_* / unlock_bench_* / unlock_task_*` 与芯片支线同用枚举位预留
  （`enabled:false`），v0.2 纯数据追加；
- 节点裁剪：砍 tier5×2（min_stage 落空）后由主策划席在 12 个内重排（再砍 1–2 个
  支线加成节点，凑不满 12 则 10 亦可）；MVP 数据全部 min_stage=0
  （评审知情项：min_stage 与 enabled 在 MVP 是无测试覆盖的预留路径，接受）。

### C3 金额格式（冲突：k/M vs ¥+万缩写）

**裁决建议：¥ + 万缩写**（采文案席），评审补充细则一并采纳：
负号前置（`-¥20万`）；万→亿进位档；Formatter 金测试须含负数与边界取整；
r 曲线（0.75→1.05）是设计端参数不进 UI；周结跳动阈值 ≥5% 照采。

### C4 文案长度预算（冲突：UI 表 vs 文案表）

**裁决建议：以 UI 表为准**（标题 ≤12 / 选项 ≤8 / toast ≤20 / 周报条目 ≤30 /
决策卡正文 ≤60），评审补充细则一并采纳：
后果预告改 **Formatter 产出的结构化数值行，不计入正文字数**（60 字装不下
3 选项×逐项 delta）；选项允许挂 1 个结构化数值后缀（如 `+¥12万`）不计字数；
texts.json 每键 `max_len` 字段 + GUT 长度断言（"唯一真源"须机械执行）。

- **Blocker**：B-1 出分输入通路（→R1）；B-2 课题收入形态（→R2）；B-3 周报节奏
  （→R3）。**Major**：M-1 测试预算（→§1.8）；M-2 算力双轨（→A15 顺延）；M-3
  影响力死资源（→R4）；M-4 竞对 8/10（→P1 收敛 8）；M-5 破产流程（→R5）。
- **Minor 已吸收**：TextService 走 L1 注入；schema 重置一次性排序；pending_decisions
  入档内容补全；移动硬杀丢周写入已知限制；试玩记录训练等待段。
- **过度设计核查**：GameWorld 门面与 accumulator 保留；A15 与"万次进 verify.sh"
  承诺已砍。
- **评审 C3/C4 结论**：均"维持+细则"，已并入 §2。
