## 四、解锁路径（定稿）

### 4.1 三通路谓词化

```
通路 1（周 RP 揭示）：按节点自身 rp_threshold 分档（~420/800/1500/2500），非全局一次性
通路 2（竞对论文外溢）：确定性规则表 + 域进度分档；修复 rv_paper_2 与 rv_paper_1 目标重复
通路 3（交叉/灵感）：parents 全 lit ⇒ 升 crossover；灵感 ⇒ rp_grant 注入（当前无效果，须兑现）
```

### 4.2 路线排他 = **定向式**（非互斥，守 DR-003）

```
投入窗口（周期末）→ 域卡三行（禁推荐序）→ 点选 = 本周期 RP 定向到该域
   域内 2–3 条路线共享该域 RP 池 → 排他由稀缺自然产生（钱不够）
   域内分路线时卡内 2 选 1（节点级选择只在此处，≤2 决策）
```

**量级（数值席）**：原稿 +15%/−10% 仅值 2.2–2.7 周供给 = **无感** → 提至 **+25~30% / −25%**，或改结构性收益（如"先走马灯 → 任务收益永久 +5%"）。
**硬门修正**：交叉硬门 **≤2**；`众木成林` 的 `lit{流水不腐}` 改加成/成本减免；**每域保一条不依赖交叉的终点节点**。
**前置依赖**：C-B2（RP = 影响力同一池）——若拆分则定向机制需重设计。

### 6.2 Σtech_bonus 上限（🔴）

草稿累加 Σtb=**4.49** → 满配 eff 上限从 117.6 崩到 **52**；3 人 Σ187 时 A=225（100 分）。
**硬约束**：**Σtb ≤ 0.92**；**单节点 tb 0.02–0.10（均值 ~0.05）**。
**关键认识**：饱和主因**不是科技树，是"3 人满配"** → 须与 θ 阶段化/上桌人数上限联标。
