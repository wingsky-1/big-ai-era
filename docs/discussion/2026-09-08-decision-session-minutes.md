### 2.4 饱和实算（B 组核心证据）

出分链（代码真源 `src/core/score_math.gd`）：`A = K·(1+eff)^0.7·(1+tb)^0.3·m·q`，K=4.0、m={1:0.6, 2:0.75, 3:0.9, 4:1.05}；`score = 100/(1+exp(-(A-95)/13))`。

| 配置 | A | score | 判定 |
|---|---|---|---|
| 1 人 eff=70 / tb=0 / tier1 / 璞石 q=0.55 | 26.1 | 0.50 | 早期无分（C1） |
| 2 人 eff=132 / tb=0.28 / tier2 / 玄冰 q=0.8 | 79.3 | 22.96 | 中盘 |
| 3 人 eff=187 / tb=0.40 / tier2 / 深渊 q=1.0 | 129.7 | 93.51 | 未饱和 |
| **3 人 eff=187 / tb=0.40 / tier3 / 深渊 q=1.0** | **155.6** | **99.06** | **饱和** |
| 3 人 eff=187 / 满树 tb=1.40 / tier4 / 深渊 | 213.4 | 99.99 | 满配封顶 |

- **score=99 的 A 阈值 = 95+13·ln99 = 154.74**（score=95 → A=133.3）。
- **饱和根源（数值席复核修正）**：**不是 tb，是 `eff=187 × q=1.0 × m≥0.9` 三者**——实算 `tier4 + 深渊 + 3 人 + tb=0` → A=**164.1 → 99.5 分**；`tier3 + tb=0` → A=140.65 → 97.1 分；要 A≤154.74 需 **tb ≤ −0.178（不可能）**。**任何 Σtb 上限都拉不出饱和区** → 这直接决定 B3 的裁决。
- **饱和触发条件**：`tier3 ∧ 深渊 3 人上桌（q=1.0）` → tb=0 即 97.1 分、tb≥0.374 即 99 分；`tier4` 时 tb=0 即 99.5 分。按供给曲线，**tb=0.374 落在 W54**（点满 6 个节点）→ **玩家 W54 即封顶**，其后 106 周无分数成长。
- **tier2 永不饱和**（tb 需 >~1.5，超满树 1.40）、**玄冰 q=0.8 永不饱和**（tb 需 >~1.9）→ **饱和的旋钮是"算力档 tier3+ × 深渊 q=1.0 × 3 人上桌"三者同时**。*（注：具体阈值随 tier 口径变化，实施时须按 `score_math.gd` 的 m 表复算并写入常数注释——对抗评审 Minor ② 指出原稿 1.472/1.766 不可复现，违反 DR-029 C-4 出处纪律。）*
- **Σtb≤0.92 的真实作用**：使满配 A≤200（实算上限 **0.9330**，A=199.60）——但 **A=199.6 → 分数仍 100.0** → 它**不解决饱和**，只防失控（数值席复核确认）。
- **A 上限 213.4 下的心跳取舍**：若保 θ=95 且满配落 ~95 分 → **k 需 40.21 → 心跳 0.62 分/A（损失 68%）**；保 k=13 → 心跳 1.92 分/A 但满配饱和。
- **θ 阶段化实算**：阶段 1（θ95/k13）心跳 1.92；阶段 2（θ150/k18）满配 213.4→**97.13 分**、心跳 1.39；阶段 3（θ220/k25）满配 213.4→**43.44 分**，扩编 eff=300→**95.55 分**、心跳 1.00。

### 2.8 关键结构性发现：gate 与科技树在单任务槽下互斥（本会实算）

单任务槽（`ST4`/`DR-023`）+ 任务表实参数（课题 35000/4 周 **rp_output=0**、研究 0 收入/150 RP/4 周、复现 8000/3 周/50 RP），lab 期 24 周内各策略：

| 策略 | 24 周收入 | gate 250k | RP 总量 | 可点节点数 |
|---|---|---|---|---|
| **纯课题**（6 笔） | **25.2 万** | **✓** | **0** | **0（科技树死锁）** |
| 纯研究（6 笔） | 0 | ✗ | 900 | 2 |
| 课题:研究 = 1:1 | 12.6 万 | ✗ | 450 | 1 |
| 课题:研究 = 2:1 | 16.8 万 | ✗ | 300 | 1 |
| 纯复现（8 笔） | 6.4 万 | ✗ | 400 | 1 |

**结论**：**gate"24 周累计收入 ≥250k"与"科技树推进（RP）"在单槽下互斥**——达标策略的 RP 产出为 0，`tech_bonus` 恒 0，出分被锁死。这不是参数问题，是结构问题。

**解法（本会裁决，绿级）**：**任务池内容化时，课题类任务补 `rp_output ~50–100`**（6 笔 → 300–600 RP → lab 期可点 1–2 个基础节点，与 GDD §3"实验室期点基础树"一致），使"钱 vs RP"从**互斥**变为**配比**。

**对 A2 的联动（已被 §2.9 取代）**：供给锚 12.3k 系「研究时间占比」连续模型；**按任务离散口径，160 周实际 RP 供给仅 ~1800–6000**（取决于任务池 `rp_output`）→ **Σrp_cost 无需调表**，改为标定任务池使供给落 `[4910, 6810)` → **P50=7 ✓**。详见 §2.9。

**顺带发现**：`balance-preview` 的供给模型（连续产出）与任务系统（离散 `rp_output`）**口径不一致**（lab 期模型 1244 vs 纯研究实得 900，差 28%）；登记为 Q13。

### 2.9 RP 供给真源裁定（对抗评审 B-1/B-5 · **本会据此修正 A 组与 C 组**）

**代码实证（全仓 grep）**：RP（=影响力同一池）**唯一来源**是任务完成时的 `rp_output`（`game_world.gd:481–487`）与事件 `rp_grant`（`event_engine.gd:190–191`）；消耗点=点树扣同一池（`tech_tree.gd:67`）。**全仓不存在"研究力每周产出 RP"的通路**。而 V6 的供给锚 11.0/12.3/13.6 kRP 恰恰来自 `balance-preview` 的"Σ研究力 195 × 研究时间占比 30/40/50%"连续模型 → **该模型在实现中无对应通路，A1/A2 的数字前提悬空**。

**实算（160 周、单任务槽串行）**：

| 任务池 RP 标定 | 160 周供给 | 点亮数（Σrp_cost=14210） | V6 |
|---|---|---|---|
| **现状**（课题 0 / 复现 50 / 研究 150） | **~1800–2400**（研究占比 30–40%） | **4–5** | **✗ 破下限 7** |
| 课题 100 / 复现 100 / 研究 150 | ~5000–6000 | 7 | ✓ |
| 课题 150 / 复现 150 / 研究 150 | 6000（40 笔 × 150） | 7 | ✓ |

**关键认识**：单槽串行下 RP 总供给 ≈ 任务笔数 × 单笔 RP ≈ (160/4)×rp = **40×rp**；**"研究时间占比"不改变总供给**（各任务 RP 产出相近时）。

**裁决（本会修正）**
1. **承认任务 `rp_output` 为 RP 的唯一来源**（GDD §7 口径 + 代码实证）；`balance-preview` 的连续模型**降级为近似参考，不再作为供给锚**。
2. **目标供给 P50 ≈ 6–7k**（使 V6 P50=7；P10≥5、P90≤11）→ 由**任务池 `rp_output` 标定**实现（课题/复现/研究均 ~100–150/笔）。
3. **Σrp_cost 维持实表 14210**（在 6–7k 供给下 P10/P50/P90 = **6/7/7** ✓ 全合规）→ **撤销 A2 的调表方案**（原方案基于 12.3k 供给，前提不成立）。
4. **RP = 影响力同一池（模块稿 C-B2，本会补裁）**：**采纳"承认同一资源"**——修订 `GDD §6.1`"只进不出"为"**可消耗（点树）**"；**翻雾供给源改为独立累计计数器 `cum_influence`**（不读当前余额，同时解决 D-12 的"点树拖慢翻雾"）。
5. **DR-027① 的"Σ≈12–16k / 供需比 1.0–1.3:1"须澄清**：若指**供给**，与实现口径差 2 倍；若指**需求**（节点成本），则与 V6 的 `[7,9]` 矛盾（供需比 1.0 意味着能点满）→ **登记 Q14**，并在任务池标定后复算。
6. **A2 的"调表"降级为条件项**：仅在"任务池标定后实际供给 >6.8k"时才需上调 Σrp_cost（复算点）。

## 十二、E5 裁决落地：短单局体验（制作人 2026-09-08 裁决）

> **裁决**：**v1.0 先做短单局体验**——一局 160 周 ≈ **26.7 分钟**（`clock.json` 10s/周 @1x）；成功标准 = "**一局从头玩到尾，有高潮、有收尾、想再开一局**"；**长线（10h+ / 多周目继承）推迟 v2.0**。**不新增"延长单局"类机制、不引入多周目继承**（后者 `DR-029 D-4` 已裁 v0.2）。

### 12.1 体验曲线实算（本会）

| 时点 | 分钟 | 玩家状态（实算） | 体验角色 |
|---|---|---|---|
| W0 | 0.0 | 开场 2 句 + 首指派 | 教学钩子 |
| W6 | 1.0 | 首复现完成、首翻雾 | "世界在走" |
| W30 | 5.0 | 玄冰（2 人 eff=132 / tier2）→ **22.96 分** | 成长段 |
| W40 | 6.7 | +tier3 → **55.19 分** | 冲刺段 |
| **W54** | **9.0** | 深渊 3 人（eff=187 / tier3）→ **99.06 分** | **★ 封顶（SOTA 时刻）** |
| W68 | 11.3 | 竞对 L3 = 75 分压迫 | 守卫段 |
| W82 | 13.7 | 竞对 L4 = 92 分（**重标后建议 ~96–98**） | 守卫峰值 |
| W120 | 20.0 | 守成（自由期三线） | 长尾 |
| W160 | 26.7 | 终局（summary） | 收尾 |

**核心风险（实算）**：**W54（第 9 分钟）即封顶，其后 106 周 = 17.7 分钟 = 单局的 66% 无分数成长**。

### 12.2 落地三条（不触已裁 DR）

1. **自由期三线提前到独角兽期（W25）**：`DR-029 C-6` 裁"计数器+差距行随 PR5/PR9b 顺手入"，**未限定阶段** → 把「霸榜周数 / 树已探明 n/14 / 影响力存量」的计数器与差距行**从上市期提前到 W25**，使玩家在 W54 封顶时**已有三线目标**（而非 W65 才出现）。
2. **后半威胁结构（N11 重标时联标）**：竞对 L4 应形成「**未满配被超 / 接近满配险胜 / 满配安全**」三层结构——实算：L4 标到 **~95 分**（需 A=133.3）时，"玄冰 2 人 + tier3 + tb=0.55"（A=133.8 → 95.1 分）**险胜**、"深渊 3 人 + tier3 + tb=0.40"（A=155.6 → 99.06 分）**安全**、"玄冰 2 人 + tier2"（A=79.3 → 22.96 分）**被超**。**约束**：L4 ∈ **[~93, ~98] 分**（A ∈[131, 146]）；现状 92 分建议微调到 ~95。**注**：**封顶玩家在 v1.0 后半是"守成"而非"对抗"**（三线接管）——**不要用"竞对反超"制造假张力**（v1.0 无扩编手段反超，属 v0.2）。
3. **封顶叙事 + 终局收尾**：封顶当周出分呈现"**已登顶 · 自由期**"（衔接 B1 护栏）；W160 给终局 summary（周数 / SOTA 次数 / 最高分 / 霸榜周数 / 树 n/14 / 影响力存量——对齐 `DR-021 B3` 的 summary 三项扩为六项）。

### 12.3 对范围的影响

- **不加**：延长单局、多周目继承、长线目标系统（全部 v2.0+）；
- **加**：三线提前（绿/黄）、L4 重标区间约束（N11 内）、封顶叙事与六项 summary（黄）；
- **不做**：为填满后半而"塞事件"（违 `DR-009` 每周必做 ≤1 与真空三件套纪律）。

### 12.4 待观察（试玩后复核）

- 27 分钟是否仍然"后半偏长"→ 若试玩反馈"W120 后无感"，候选：**终局提前到 W120（≈20 分钟）**（须复议会 `DR-028/029` 阶段表）或**提高三线目标密度**（不触 DR）；
- 封顶时点（W54）是否过早 → 若需延后，走 `θ/k 阶段化`（复议队列第 3 项，v0.2）。
