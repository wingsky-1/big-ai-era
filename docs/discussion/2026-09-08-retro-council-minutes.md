## 一、根因定论（四席独立收敛）

规范都在文档里，流程无卡口强制执行——规范无检查点=不存在。缺陷是排期/规格/实施/验证四卡口连环放行，禁只追下游。

## 二、裁决表（DR-030 摘要）

| 机制 | 关键裁决 |
|---|---|
| 规格翻译 | 验收锚前移 DR 立裁时；≥3 条验收 checkbox；lint 两硬规则+内容审+L 抽检 |
| 实施对账 | 自证证据只引用不复述（+GUT passing 行）；三方对账=显式 scene_path+调用面集合（S4 补丁：DASHBOARD/TASK_MGMT 零调用面，断言"确无调用且无场景"）；共享键常量化 |
| 试玩闭环 | 反馈表单 issue 化；回写复核；停线复盘（影子先行；判定权制作人席） |
| 反馈沉淀 | 模板字段"说不出防哪条缺陷即删"；设计债销账 |
| 度量回顾 | 里程碑四行式（+流程漂移）；过时文档清单；字段命中率 |
| 流程硬件 | 无 issue 不合码（issue-gate+分支保护由制作人配置）；lint 永不进 verify.sh |
| I/O 契约 | 十席四要素+拒收权（主程序拒领未过检 issue/code-review 打回无自证 PR） |
| 全局责任 | 跨席找茬/流程提案权平等（process 标签）/逃逸共担/下游省工自问 |
