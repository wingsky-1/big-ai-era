## 1. 设计公理（从愿景反推，供各席共用）

1. **"圈内人玩梗，圈外人玩经营"（DR-013）**——梗必须挂在机制上，不能只改名字；经营必须自洽到不看梗也能玩。
2. **实时流淌的密度是"信息密度"而非"操作密度"**（DR-009）——真空三件套兜底，禁止用事件塞满。
3. **成长必须有三重来源且互相竞争**：人（研究力）/ 算力（档位）/ 知识（科技）——三者抢同一份资金与时间。
4. **竞对是节律器不是对手**（B1）——它的功能是"制造时限与参照系"，不是"可击败的 AI"。
5. **每个系统必须至少有一条"输入边"和一条"输出边"**——否则是装饰而非系统（本次决策网审查的判据）。
6. **分数是可截图的社交货币**——出分/命名/霸榜三件事必须能被截图传播。

## 2. 目标可达性配平（核心议题；含主持人复核）

### 2.1 问题陈述（实证）

玩家侧当前出分与竞对分数的量级差距：

| 口径 | 配置 | A | score |
|---|---|---|---|
| 现实现（单槽单人 eff=70） | tier1/璞石/tb0 | 26.1 | **0.5** |
| DR-005R 求和 eff=187 | tier1/璞石/tb0 | 51.6 | **3.4** |
| 求和 eff=187 | tier2/璞石/tb0.2 | 68.1 | 11.2 |
| 求和 eff=187 | tier4/璞石/tb0.3 | 97.7 | 55.1 |
| 求和 eff=187 | tier4/深渊/tb0.55 | 187.2 | 99.9 |

竞对实表（`src/data/rivals.json`）：L1@~12 周 **35** 分、L2@~54 周 **58** 分、L3@~68 周 **75** 分、L4@~82 周 **92** 分；W0 基线（灵犀 Chat）**24** 分（来源=`opening.json` rival_best / `benchmarks.json` baseline，非 rivals.json——A 路 Minor 修正）。

**结论：按"开局三人求和 + 璞石 + tier1"的典型早期配置，玩家 3.4 分 vs 竞对首模型 35 分——早期不可能反超，"璞石贴 L1@12 周"（GDD §9 对位）在数学上不成立。**

### 2.2 反解表（主持人精确复算，θ=95 / k=13）

| 目标分 | 需要 A | 追 L1 所需 eff（不同配置） |
|---|---|---|
| 3.4 | 51.5 | — |
| 10 | 66.4 | — |
| 25 | 80.7 | — |
| **35（L1）** | **87.0** | tier1/璞石/tb0：**395**；tier2/璞石/tb0.2：**265**；tier4/璞石/tb0.3：**158**；tier3/玄冰/tb0.3：**115**；tier4/深渊/tb0.55：**62** |
| 58（L2） | 99.2 | tier4/深渊/tb0.55：**75**；tier3/玄冰/tb0.3：**139** |
| 75（L3） | 109.3 | tier4/深渊/tb0.55：**86**；tier3/玄冰/tb0.3：**160** |
| 92（L4） | 126.8 | tier4/深渊/tb0.55：**107**；tier3/玄冰/tb0.3：**198** |

> **复核说明**：数值席提案的反解表（35→81.6 / 58→93.8 / 75→106.9 / 92→124.6）使用了 `A = θ + k·ln(p/(1−p))` 且 p 未除 100，系统性低估 A（差 +2.2~+5.4）；本表为修正值。数值席"结构性不可达"的**方向结论成立**。

### 2.3 候选解法与主持人倾向（**经 A 路评审修订**）

| 方案 | 动作 | 优点 | 代价/风险 |
|---|---|---|---|
| **甲 竞对分数重排** | 离线一次性标定死表 | 改动面最小；恢复 GDD §9 对位 | **前提 = Σ 落地 + 训练位多人上桌（[change]）**——A 路 B4：代码 eff=单人 70 → W12 仅 0.89 分；Σ 落地后才 10.2 分。否则 L1 须标 ≤0.89 分 |
| **乙 K 重锚** | K 4.0→~7.2 | 单常数改动 | **早期过强**（K=7.2 下 W12 A=119.4→86.7 分）；且"饱和"非乙独有（K=4.0 满配本身 100 分封顶）——原稿排除乙的论据自相矛盾（A 路 B3） |
| **丙 分数映射重标** | θ/k 上移放大 | 解决后期饱和 | 触碰 DR-027③ 冻结；**单独使用不足以解决早期可达**（A 路 Major 1：仅轨2a 时 W12 仍 10.5 分） |
| **丁 供料链** | 任务→训练供料（走 tb 的 Σ 扩项） | 同时解 C2；给早期加乘子 | 依赖 E1（任务槽挂人）；须走 DR-005R 复议 |
| **戊 A 上限** | 训练位上桌人数上限 | 压缩 A 动态范围（11× → ~4×），使 sigmoid 可用 | 与 DR-029 A-1 最低档的兼容性须确认；触碰 B10 → [change] |

**主持人倾向（修订）**：**戊 → 丙/乙 → 丁 → 甲 的联标顺序**——先定 A 上限，再解 K/θ/k 自洽组，再叠加供料链，最后按玩家成长曲线标竞对死表。**任一单件都不足以解决 C1**（详见 §7.1）。

### 2.4 必须提级的"时限发现"

**DR-005R（求和 eff，A 上限 ~187→扩编后更高）与 DR-027③（θ=95/k=13 冻结）在量纲上不兼容**：前者使 A 增长到 190+（扩编后更高），后者在 A>130 即饱和（A=130→93.7 分，A=150→98.5 分）。两项均为"已裁"，冲突须走轻度复议（circuit-breaker §5：试玩证据 + 一次一议 + 黄级），不得由本稿静默改判。**A 路补充**：A 动态范围实测 ≈11×（W12 54 → W82 595），sigmoid 有效分辨区仅 ≈2× → 见 §7.1 四件套联标。

**试玩证据可先行**：v0.1.3 反馈④a"一个任务只能指派一个人？"→ 单槽单人 vs 求和口径的落差已在真人反馈中出现。

## 4. 玩法架构总图（主策划席提案 · 待裁）

| 层 | 目标 | 玩家的决策 |

### 4.2 五系统互锁拓扑与"空转警示"

```
任务 → 配方/供料 → 训练 → 出分 → SOTA
训练 → deploy → API 收入（v0.2）
树   → tech_bonus → 训练
任务 → RP → 树
竞对 → 论文外溢 → 翻雾
经济 → 钱/卡时 → 任务·训练
事件 → 9 效果 → 全系统
```

**空转警示（任一成对缺失即空转）**：任务 × 训练 = 规划空心（C2）；树 × 训练 = 点树成收藏；经济 × 任务 = 钱无机会成本（C3）；训练 × 竞对 = 截图失效（C1）。

### 7.3 C3 压迫感：裁决

- **根因裁定**：压迫感来自"**脉冲节奏 × 支出刚性**"的错配，而非收入高低。当前"每周高频随机脉冲"抹平了节奏 → 破产线与发薪日焦虑不成立。
- **裁决（采纳主策划席的结构性口径，经 B 路评审限定）**：**实验室期 / 独角兽期的经营收入只来自占槽任务结算**（无被动经营收入）——与 GDD §6.2 原意一致（"课题=第三类任务，~4–8 周、~30–80k/笔"）；`economy.accrue_week` 的"每周 roll"形态不得作为 v1.0 收口值。**限定**：**上市期的 API 常量收支行为结构必要件（DR-028R R-1R 维持，边界提案 #30 已收拢 v1.0）**，不属本条禁令范围——B 路评审指出原稿"无被动收入 + DR-028R 维持"字面对冲，此限定消除该矛盾。由此同时获得：低频大额（节奏）+ 与研究互斥（机会成本）+ 支出刚性高频（工资 ~2k/人·周 + 卡时）。
- **数值席两项发现采纳**：①独角兽期融资占比（12.5%）与目标（25–40%）差一倍 → 融资量级重标归 PR10；②上市期结构性赤字 ~20k/周成立（API 常量为必要件，DR-028R 维持）。
- **移动休闲画像的弃游红线处置**：①"破产 Game Over 清档"→ 登记 **v0.2 候选"破产软着陆"**（重组状态/掉声誉/裁员工，与融资软缓冲同批）；②"决策卡阻塞=人质"→ 登记**轻度复议候选**（试玩证据：本次画像 + v0.1.3 反馈①②）；③"离线掉名次"→ **不成立**（DR-022②"只在场才流淌"已解，离线不推进竞对）。

**新增推演：gate 值与阶段时长在两种收入口径下都不自洽（主持人）**

| 收入口径 | 累计经营收入 ≥~250k 达标时点 | 与"实验室期 0–24 周"的关系 |
|---|---|---|
| 当前实现（每周随机脉冲 35–92k） | ≈ W3–W7 | **过早**（阶段晋升提前到 W5，实验室期玩法未展开） |
| 占槽任务结算（课题 ~55k/6 周 + 复现 ~8.5k/4 周交替） | ≈ W40（全接课题 ≈ W30） | **过晚**（超出实验室期 ~6–16 周） |

**结论**：`gate 累计收入值` 必须与 `任务池参数 × 阶段时长` 三者联标（数值席硬约束 #3：`Σ周均收入 ≥ gate 累计收入 ÷ 窗口周数`），且**必须在任务池内容化落地后重标**——这是"收入=占槽任务结算"裁决的配套前置，否则阶段节奏错位。另：影响力门槛 ~50 在 W2–W4 即满足，实际由收入卡住（门槛值形同虚设，归 DR-029 C-2 gate 三值标定/等试玩池）。

## 8. 子系统功能特性总表（主持人整合稿）

> 列义：定位 / 玩家决策 / 输入边 / 输出边 / 失败态 / 反馈 / 版本归属 / 硬约束。评级针对"本次设定新增项"。

### 8.1 员工系统（StaffRoster）——决策网的人力枢纽

- **定位**：唯一不可直接购买的稀缺资源；"人"是全部决策的机会成本载体。
- **玩家决策**：谁上桌（训练）/ 谁跑任务 / 谁待命；特质组合（v0.2）；招聘与签约金（v0.2）。
- **输入边**：招聘（v0.2）；**无其他输入**（人是外生给定）。
- **输出边**：research_eff → 出分；任务速度/产出（E1 待补）。
- **失败态**：无空闲员工 → 指派拒绝 + 原因可见。
- **反馈**：主台常驻实体卡（V1-03）+ 状态字样 + 观察文本（DR-029 A-8）。
- **版本**：MVP 3 人；特质/condition/招聘/图鉴 v0.2。
- **硬约束**：`eff 聚合口径唯一（Σ，DR-005R）`；**不设上桌人数上限**（轨 2b 已撤销，§7.1）。

### 8.2 任务系统（TaskQueue）——日常收入引擎与时间骨架

- **定位**：决定玩家在"赚钱"与"攒知识"之间的每周分配。
- **玩家决策**：接哪条任务（课题/复现/研究）；谁进任务槽；是否为训练让路（猛火形态）。
- **输入边**：员工（E1 待补）、资金（cost）、科技（unlock 谓词）、时间。
- **输出边**：资金（income）、影响力（rp_output）、迷雾（RP 供给）。
- **失败态**：资金不足 / 谓词不满足 / 无空闲员工 → 拒绝 + 原因。
- **反馈**：入队即时高亮、完成自动顶入队首（ST5）、进度刻级。
- **版本**：MVP 5 类任务；任务池内容化 v1.0（绿）。
- **硬约束**：lab 期收入占比 课题 ~55 / 复现 ~45（DR-028§四 占比纪律）；**"脉冲"在本稿口径下即"占槽任务结算"，非独立被动收入**（§7.3）。

### 8.3 训练与出分系统（TrainingProject + SotaBoard + 命名）——高潮发生器

- **定位**：全游戏的"截图时刻"与情绪峰值；命名=玩家参与仪式。
- **玩家决策**：训哪个基座（q 权衡）、几人上桌（eff）、何时开训（撞竞对窗口）、命名与宣发档。
- **输入边**：员工（eff）、科技（tech_bonus）、算力档（m）、资金（cost）、基座参数。
- **输出边**：分数 → SOTA → 影响力（E2 待补）、竞对对照、命名图鉴。
- **失败态**：eff=0 / 资金不足 / 档位不足 / 已有训练 → 拒绝 + 原因。
- **反馈**：进度刻级（值变才发）、出分全屏（L3 预算内）、命名框 z2 阻塞。
- **版本**：MVP 已落；改名卡/宣发档 v0.2（边界提案口径）；**上桌人数不设上限**（轨 2b 撤销）。
- **硬约束**：`θ/k 标定须使"玩家可达 A 范围"与"竞对分数目标带"同区间`（见 §7.1 修订）；训练周=定值不随机（DR-001）。

### 8.4 科技树与迷雾（TechFog + TechTree）——中长线目标与探索感

- **定位**：网状迷雾=四件套之一；提供"探索感"与中长线目标。
- **玩家决策**：点亮顺序（域优先）、RP 分配、交叉节点时机、长忆路线二选一（内容席形态）。
- **输入边**：影响力（rp_cost）、竞对论文外溢、交叉进度（lit 数）。
- **输出边**：tech_bonus → 出分；tech_lit → 任务解锁；域计数 → 图鉴。
- **失败态**：状态非 researchable / RP 不足 → 拒绝。
- **反馈**："???"变实名、域计数 n/14、周报迷雾行、1-hop 微图。
- **版本**：MVP 14 节点；长忆/器用节点名（Q4）；谓词化补边（黄）。
- **硬约束**：14 节点口径三处一致（GDD §8.1 表 / 域计数分母 / 实表）；~~Σrp_cost ∈[~8k,~12k]~~ → **实表 Σrp_cost=14210 已越界上限 12k（A 路 M4 实证）→ 新立 N16，须 GDD §8.1 同步或调表**。

### 8.5 事件系统（EventEngine）——节奏调节器与叙事注入点

- **定位**：不是收入源；是节奏与叙事的注入点，且必须"只在结算点产出"（DR-012）。
- **玩家决策**：决策卡选项（每项带代价）、稍后处理时机（本周结前强制）。
- **输入边**：谓词（钱/影/周）、RNG 域 3。
- **输出边**：9 效果类型（资源/任务/训练/迷雾/旗标）。
- **失败态**：选项不可负担 → 置灰 + 原因；未解锁选项不出现。
- **反馈**：z2 阻塞卡 + 选项预览句 + 当周周报事件行；通知层零红点。
- **版本**：MVP 8 卡；三层池 30–37（v0.2）。
- **硬约束**：每周 ≤1 决策卡；同周双卡顺延确定性入档。

### 8.6 竞对系统（RivalTrack）——节律器与参照系（不是可击败的 AI）

- **定位**：制造时限与参照系；**玩家无直接决策**（严守 B1）。
- **玩家决策**：无直接决策；仅确定性互动（抢发文案/传闻窗口，v0.2）。
- **输入边**：无（脚本 + ±15% 扰动）→ E6 仅可加确定性互动。
- **输出边**：分数（榜单压力）、论文外溢（迷雾翻态）、预警（节奏）。
- **失败态**：不适用（不可操作）。
- **反馈**：发版播报、预警黄/红灯、周报宿敌行与"落后为什么"行。
- **版本**：MVP 8 动作；传闻池/挖人 v0.2；潮汐/北岭=红级专项。
- **硬约束**：永不引入博弈 AI；预警红灯零误报。

### 8.7 经济系统（Economy）——张力来源

- **定位**：压迫感的唯一来源（脉冲节奏 × 支出刚性）。
- **玩家决策**：买卡/扩编/接脉冲/危机三线（v0.2）。
- **输入边**：任务、事件、融资（v0.2）、API（v0.2）。
- **输出边**：工资、训练成本、买卡、科技成本。
- **失败态**：资金不足拒绝；触及破产线 → Game Over 短路。
- **反馈**：资源栏刻级跳动、警告线提示、周报收支行、净流入预告（体验席）。
- **版本**：MVP 双来源；融资/API/支线/影响力出口 v0.2。
- **硬约束**：脉冲周期形态（非每周随机）；破产率断言 V1 双断言。

## 18. 顶层节奏框架【提案 · 2026-09-08 制作人方向输入后产出】

> **提案状态声明**（体验席 B 路径评审指出"仓库零记录"，本节约为补录）：本节内容源于制作人 2026-09-08 口头下达的四条目标 + 主持人当轮综合，**尚未经人类拍板、未进任何 DR**，引用时须标"提案"。

### 18.1 制作人四条目标（方向级输入）

1. **先实现 MVP 验证核心玩法**；
2. **最终是长线游戏，参考《游戏发展国》的节奏——多系统目标交替权重**；**不是固定唯一解**，要给玩家充分自由选择 + 一定随机性；
3. **竞对是关键的压力来源 + 与现实结合加强体验感的方案**；
4. **每个系统要约束好边界，为整体"可玩、好玩"服务**。

### 18.2 训练周期节拍器（提案）

```
训练周期（10–26 周，随基座变长）
├─ 周期内：攒钱 / 攒知识 / 攒人力（三线并行推进，玩家微调）
├─ 周期末：出分高光（命名 + 上榜 + 差距行）
└─ 投入窗口：决定下个周期主抓哪个系统  ← 权重交替发生在这里
```

### 18.4 权重交替 = 收益窗口重叠（提案）

- **不是推荐序列**：任一周期内 ≥2 个系统处于"同量级可选"区间，否则是伪选择。
- 三行并列、**无排序、无"推荐"标**（文案由确定性条件分支生成，零 RNG）。
- 依据行示例：竞对行（"深巷 L2 距今 ~9 周，预警黄灯已亮"）/ 现金行（"下周净流入 -¥~3万，跑道 ~7 周"）/ 灵感行。
- ⚠️ **数值前提未满足**：`module-req-batch-b.md` §4.1 推演显示知识轴边际收益比员工/算力低 ~20 倍 → 交替在数值上暂不成立，须先解该问题。

### 18.5 系统边界卡四问（提案 · 制作人目标④落地形态）

| 问 | 作用 |
|---|---|
| 它独占什么？ | 防资源重复 |
| 它给谁供料、向谁索取？ | 定接口边 |
| 复杂度预算？ | ≤2 决策 / ≤1 屏 UI / ≤3 数据表键 |
| 它坏了整体会怎样？ | 定优先级（P0/P1/P2） |

**系统数量上限 6 个**：训练 / 任务 / 员工 / 算力 / 知识 / 竞对（经济=资源层、事件=调节层，不计入 6）。

### 18.6 随机性口径（待裁）

| 类型 | 例子 | 建议 |
|---|---|---|
| **情境随机** | 出现哪个事件/哪条任务/竞对时序扰动 | ✅ 可加（落在已裁两处 RNG + 确定性变化内） |
| **结果随机** | 出分浮动、任务奖励浮动、员工属性随机 | ❌ 维持冻结（DR-001"结果成败不随机"） |

**确定性变化三形态（体验席）**：①池序重排（按已亮域/已花影）；②轮转（假 arXiv ~4 周、F1 吐槽池、默认名池游标）；③局内状态驱动切换。**不背表**：序列由玩家自己的前置决策决定，轮转周期 > 单局长度。
