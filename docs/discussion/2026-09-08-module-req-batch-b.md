# B 路径模块需求文档（知识 / 事件 / 员工三模块 · 2026-09-08）

> **性质**：模块化需求文档（设计产物，非裁决）。承载制作人 2026-09-08 裁决的 **B 路径**——"先写不依赖地基问题的系统需求文档，并行推进地基裁决"。
> **范围**：仅三模块（① 知识系统=科技树+迷雾 ② 事件系统 ③ 员工系统）。**训练/任务/算力/经济四系统不在本卷**——它们卡在地基问题（C1 参数组 / C3 收入口径 / N9+N10 算力闭环）上，写需求文档必然返工。
> **纪律**：不发明任何新裁决、不重开 DR（复议走 circuit-breaker §5 一次一议）；数值一律 `~` 占位；验收点全部带 `[T]`（GUT 用例名）或 `[P]`（试玩主观）；功能点全部有出处（GDD 行 / DR 号 / 试玩反馈 / 实证）。
> **状态**：四席可行性讨论已回（主策划/数值/内容/体验），主持人裁决已并入；**待人类拍板项见 §七**。
> **关键发现**：四席交叉一致的三条 Blocker（事件层失控 / 员工 Σ eff 未落地+无上桌约束 / 知识谓词未落地+Σ 越界）——见 §六.1。

### 0.1 制作人四条目标（本卷一切设计的约束）

| # | 目标 | 对本卷的约束 |

### 0.2 已定顶层框架（上一轮圆桌 + 两路对抗评审）

- 主玩法=训练出分霸榜；三条资源线（员工/任务/知识）；压力源（竞对/经济）；调节器（事件/阶段）。
- **节奏骨架=训练周期节拍器**：训练周期（10–26 周）→ 出分高光 → **投入窗口**。
- **权重交替=收益窗口重叠**（不是推荐序列）。
- **系统边界卡四问**：独占什么 / 给谁供料向谁索取 / 复杂度预算（≤2 决策、≤1 屏 UI、≤3 数据表键）/ 坏了整体会怎样。
- **随机性纪律（DR-001）**：随机仅竞对扰动+灵感两处，全部周结消费；"揭示时机随机、结果成败不随机"。制作人追加：**情境随机可加、结果随机维持冻结**（待裁）。

## 四、主持人侧独立推演（待圆桌验证）

### 4.1 权重交替在数值上**目前不成立**（关键发现）

按 `A = K(1+eff)^0.7(1+tb)^0.3×m×q` 计算各系统的**边际收益**（基线 eff=187 / tb=0.3 / tier=2 / 璞石 q=0.55）：

| 投入 | ΔA | Δscore | 相对量级 |
|---|---|---|---|
| 知识：+1 个便宜节点（tb +0.05） | 0.70–0.95 | **+0.6 ~ +0.8** | **1×（基准）** |
| 员工：+1 人（eff +62） | 12.6–19.5 | +3.3 ~ +26.6 | **~20×** |
| 算力：+1 档（m 跳变） | 13.95 | +7.9 ~ +25.5 | **~20×** |
| 基座：璞石→玄冰（q 0.55→0.8） | 31.7 | **+49.6** | **~60×** |

**结论**：知识轴杠杆比员工/算力低约 20 倍、比换基座低约 60 倍 → **玩家永远应优先买卡/换基座/扩编，最后才点树** → "多系统目标交替权重"（制作人目标②）在数值上**不成立**。

**根因**：`(1+tb)^0.3` 的指数仅 0.3，且单节点只给 0.05–0.25（全树 Σ=1.40）。

**候选解法（待圆桌与人类裁决）**：

| 解 | 做法 | 副作用 |
|---|---|---|
| A 提节点值 | 单节点 tb 0.05→0.15–0.2 | 全树 Σ 会到 4+，(1+tb)^0.3 放大 → 与 C1 参数组联标 |
| B 提指数 | 0.3→0.5（触碰 DR-005） | 改变公式形态，红级 |
| C 给知识非分数收益 | 解锁任务/降低训练成本/提升供料效率 | 需新机制；但最符合"知识=能力"直觉 |
| D 降其他轴杠杆 | 削 q/m/eff 跳变 | 与 C1 四件套冲突 |

**主持人倾向**：**C（给知识非分数收益）+ A（适度提节点值）**——C 不触碰公式且最符合题材（点树解锁能力），A 作为数值微调。

### 4.2 收益窗口重叠的可行性（若 4.1 的解法落地）

- 早期（W10–25）：tb 低 → 知识边际高；eff 低 → 员工边际高；tier 低 → 算力跳变大 → **三选**
- 中期（W25–50）：tb 0.3–0.8 边际递减；eff 已 187+；算力仍是大跳变 → **二选**
- 后期（W50+）：tb 近满、eff 高、算力顶档 → 需经济（deploy/融资）接棒

**判据**：任一周期内 ≥2 系统的边际收益处于"同量级区间"（建议同一数量级内），否则是伪选择。

### 4.3 情境随机的可行落点（不破 DR-001）

| 落点 | 形态 | 是否触 DR-001 |
|---|---|---|
| 竞对时序 | ±15% 扰动（已裁） | 否 |
| 灵感时机 | base/pity/cap（已裁） | 否 |
| 任务池出现顺序 | 池序轮转（确定性） | 否（零 RNG） |
| 翻雾目标 | 从可翻节点中按表序/条件分支选 | 否（零 RNG） |
| 事件候选 | 谓词过滤后按权重抽（已裁） | 否 |

**结论**：情境随机可全部落在"确定性变化 + 已裁两处 RNG"内，无需开新 RNG 域。
