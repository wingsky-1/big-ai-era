## 1. 制作人反馈五条（原文）+ 逐条理解

### 反馈 1：员工、竞对公司、模型——贴合现实，但不要是真实的现实
**理解**：内容方向要求。机制与生态拟真（圈内人看得懂的节奏、梗、演进脉络），
但一切专名虚构换皮——不影射真实公司/人物/模型/榜单。
**冲击面**：
- 第一轮 balance 示例的 `base_qwen_1b`、`mmlu` 等真实名 → 全部换虚构名；
- 第一轮术语表"评测名保留英文原词（MMLU/HumanEval 等）"规则 → 修订；
- 竞对机构名（第一轮 3 候选保留为风格参考）+ 竞对模型名、员工名与特质、
  高校/课题来源等全部需虚构化风格卡。

### 反馈 2：保留模型命名权给玩家
**理解**：新机制——玩家给自己的模型起名。这是低成本高收益的仪式感设计
（SOTA toast 上出现玩家起的名字 = 核心心跳时刻的个性化放大器）。
**待设计面**：命名时机（立项命名 or 出分宣发时）、长度/字符约束、入档字段、
竞对榜单与播报如何引用玩家命名、与 texts.json 体系的边界（玩家输入≠翻译键）。

### 反馈 3：科技树不要线性——网状迷雾 + 非线性解锁 + 随机性（本轮最重方向修正）
**理解**：第一轮科技树是"已知全貌的规划树"（tier 分层 + prereq 四元组）；
制作人要的是**探索未知的科研过程**：
- **网状**：贴近真实 LLM 演进脉络（多前置、跨线汇流、时序涌现），以及设想中的
  其他道路（构思支线）；
- **迷雾**：没研究到就看不见——渐进揭示，"未知的未知"；
- **非线性解锁**：解锁条件多元——自身研究等级够高 / **竞对发论文外溢** /
  **交叉研究积累** / 随机灵感等，不是单一 prereq 链；
- **随机性**：要有，但需与确定性模拟/存档/测试兼容（见碰撞点 1）。
**冲击面**：第一轮 B19–B26 全系列（混合型/四元组/15 节点清单/tier 结构）、
C2 效果池、producer"列表式 UI"裁决（迷雾网状下的界面形态待重议）。

### 反馈 4：搞清楚核心循环与成长路径、玩家交互感——哪些是主要系统、体验感怎么加强
**理解**：回到体验层面重审。要求产出：
- 主要系统的权重排序（研究/训练/竞对/事件/员工/科技……在玩家心里的占比）；
- **玩家交互节奏表**：每周/每 30 秒玩家的手在做什么（决策点清单+密度区间）；
  第一轮对抗评审已警告"训练等待段=第一个无聊瞬间"，此处正面回应；
- 体验峰值设计（心跳时刻）与成长路径的体验演化（三阶段玩什么不一样）。

### 反馈 5：研究 / 模型 / 部署怎么分配比重，经济来源
**理解**：玩法权重随三阶段演化（实验室=复现+论文为主；独角兽=训练大模型为主；
上市=部署 API 为主）+ 经济来源链的切换（课题赞助→融资→API 收入）。
**冲击面**：R2（课题收入形态）需扩展为完整的经济演化模型；
economy 收入侧结构、任务类型集、160 周/三阶段各 50 周锚点下的比重曲线。

## 1.5 世界观时间锚点（制作人补充）

- **游戏开局 = ChatGPT 发布时刻（2022 年 11 月末）**——"你听说 ChatGPT 发布了，
  决定把实验室的研究方向转向大模型"是天然的开场叙事。
- **迷雾科技树的现实参照系**：ChatGPT 之后的主流演进脉络（推理增强→开源权重
  浪潮→长上下文→多模态→工具调用/Agent→对齐与评测军备→……）作为网状科技
  树的骨架参照，**全部虚构换皮**（配合反馈 1）；
- **竞对时间线起点**：发布时刻起业界进入军备竞赛——竞对 8/10 动作时间线、
  事件卡池（算力涨价潮/开源冲击/安全争议）均以此为纪元元年；
- **经济背景红利**：2022 后融资潮与算力涨价并存，为反馈 5 的经济演化提供
  现实节奏参照。
