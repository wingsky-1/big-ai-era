## 二、数值审查发现（主持人新增，两案）

1. **基座质量乘子 q(base) 缺失**：数值席 a_band 自洽依赖"min_staff 约束下 eff 物理上限"，但**未闭合**"大材小用"漏洞——若 quality_mult 全 1.0，eff195 三高手训璞石 1b 可打出 A≈96（超 [40,70] 带）冲榜。**要求 v0.1.0 即给基座差异化 q 值**（璞石 ~0.55/玄冰 ~0.8/深渊 1.0，纯数据=绿级，PR6 落表前由数值席精算）。已列入 V-sim 复算点。
2. **API 占比断言分阶段**（两席数据冲突消解）：制作人"deploy 周收入≤40%"断言适用于**实验室/独角兽期**（防过早依赖）；上市期 API 主力（55–70%）是 GDD 三阶段设计意图，断言改写为"上市期 API 占比 ∈[50%,70%]"（阶段结构断言）。

## 五、支线危机收入（回应"保留支线应对危机期"）

- **危机定义**：cash<警告线（-30k~）=危机态（软态、零 RNG）
- **v0.2 第一批（事件卡级，绿）**：贷款（偿还见 R-8）/ 设备出售 / 接私活（+2.5k/人/周，该员 research_eff×0.5 两周，出危机自动停）
- **常驻案（升级蓝本，黄）**：算力出租（富余卡时×0.30k，上限 20 卡时/周，当周不可撤）/ 企业咨询（影响力≥50，U(15,35)k/2 周，占 1 人+冷却 10 周）/ 开源赞助（影响力≥80，按 score 一次性 25/40/60k+影响力 10–20，模型退出部署池，12 周≤1 次）/ 接私活转常驻
- **防刷四闸**（主策划+制作人共识）：谓词触发不可购买、冷却/once、占任务槽机会成本、同类递减（stage_depr 表驱动模式）
- **标定目标**：危机态三线并发 8–15k/周 ≥ 固定支出 60%，撑 6–10 周
- 政府基金砍除（与融资语义重叠）

### 锚点 2：纯参数差异是否足够（触发 R-1 复议）
**判断：节奏差=参数够；结构差=必须新增，数学上没有第三条路。**
- 上市期结构性赤字 ~30–40k/周（支出 46–58k vs 纯参数课题周均 ~12k）；两条纯参数补法皆崩：加大脉冲需 ~440k/笔且一次空窗 ~570k 摆动构造性穿越 -200k 破产线（"脉冲时序轮盘赌"，经营决策归零）；加密到 3 周间隔则与实验室期同构（数值通胀≠节奏差）
- 实验室期纯参数足够；独角兽期**融资脉冲是设计好的答案而非可选**（压力换型：破产风险→稀释代价+玩家主动择时）；上市期 **API 常量收入必须**（deploy 黄级激活）；财报日=压力节律器非收入源，事件卡化即可，不必做成系统

**主持人复议 R-1R**：原 R-1"两个例外"改判——融资收支行与 deploy API 收支行从"允许的例外"升级为**"三阶段结构差的必要件"**（独角兽=融资、上市=API，缺一则该阶段经济数学上不成立）；财报日维持事件卡化；估值/股权入档红级否决**维持**。v0.2 经济稿第一批相应调整为：deploy 行+融资行+支线 3 卡同批（参数表先行，逐项独立 PR 过断言）。

### 锚点 3：影响力门票定价量级
- 统一汇率 ~1k¥/影响力（咨询单机会成本反推 ~1.1k/影）；门票表：咨询 30/赞助 40（净 20–30）/企业专享 API 档 60–80；**危机两线（出租/私活）0 门票——救生索不设闸**
- 标尺：单次门票 ≈ 解锁时点影响力存量的 15–25%；前提 160 周累计 ~300–600（~占位）
- **新空白**：影响力累计曲线预演报告未覆盖——主策划锁曲线后联标（门票×汇率×融资估值共用同一存量）；v0.2 出口开后"三口互挤"须 V-sim 影响力分配压力测试
