## 议题 A：部署（deploy）玩法闭环
- 玩家可见：训练出分后模型卡"部署上线"按钮；次周周报新增"API 收入"行；竞对发版周收入行红色下箭头+"深巷新模型分流用户"旁注；训练位分岔：冲 SOTA vs 热更新
- 机制：deploy=五类任务矩阵占位行转正（ST3），一次性启动动作，占任务槽 N 周+结项资金；解锁谓词=持有评分≥上线线的未部署模型（谓词成对注册=黄，DR-011）
- 完成进"在线位"（v0.2 单在线位起步）；API 周收入=economy.accrue_week() 第三收支行（E 矩阵黄级兑现 DR-006 占位）
- 挤压度=确定性查表：我的在线分−霸主分 → 收入衰减；不加第 4 RNG 点；竞对"涨价引用"可联动抬单价（DR-023 复用）
- 维护=对在线模型"热更新训练"：复用 training 管线（占训练位+Σresearch_eff），刷新在线分；挤压超阈值黄灯/红灯提示（复用 RV4+DR-027④ 节奏），是提示不是必做
- 资源竞争：deploy 占任务槽、热更新占训练位与研究员、在线服务每周占算力余量；DR-018 超分配拒绝随 v0.2 恢复（卡时不足明确拒绝）
- 对齐 DR-009：每周多 1 个非必做取舍，周必做仍≤1；被动收入加厚缓解真空焦虑
- 冲突点：周报 Q6 字段集已冻结→API 行/挤压旁注=v0.2 扩字段（只增键=黄）；热更新频率需数值席给冷却下限防破坏节奏

## 议题 B：主线 vs 支线职责划分
- 口径：主线=排任务时可计入预期（课题+复现+API）进"规划账本"；支线=事件卡/传闻的计划外收入，只进周报"计划外"行，永不进预期（DR-012 只在结算点产出）
- 防刷四闸：①不可购买触发（仅谓词）②冷却/once（字段在册）③机会成本（占任务槽挤掉课题）④同类重复收益递减（stage_depr 表驱动模式复用）
- 危机期体验：跌破警告线 -30k → 资源栏红色常驻+周报头条"现金流预警"+"救急支线池"解锁（贷款/私活/设备出售，纯事件卡=绿）；救急卡权重与低现金正相关（low_money 谓词=黄只读不入档）；"有人递绳子"非惩罚；贷款带后续周偿还（delayed money 效果已有）防无痛续命
- 角色联动：traits 占位（黄）——灌水达人加成支线/圈内人脉解锁专属支线；影响力=高级支线准入门票（v0.2 消耗口，DR-022⑩）
- 冲突点：救急卡若为决策卡占每周 1 张额度（接受，救援本身=有效决策）；"被动流近无风险"不破——支线只在低现金窗口加权

## 议题 D：MVP 兼容路径
- v0.2 第一批（黄，依赖序）：①deploy 收支行+单在线位 ②tasks deploy 行实装+上线谓词 ③low_money 谓词+救急池权重 ④融资决策卡（零新效果枚举）⑤周报 API 行+跑道行（texts 增键=绿）
- 等试玩反馈：热更新频率/挤压强度/支线冷却递减/财报周期/影响力定价
- 绿级：救急/传闻事件卡、特质组合表（待 traits 落地）
- 红级：零新增红。守三条：周结管线不插步（API 在第 1 步收支内部）、RNG 点不增、单在线位起步；融资稀释若需股权入档=迁移红 → 建议 flags 开放容器记融资次数（零迁移）
- 迭代序：v0.1.0 试玩→数值迭代轮→deploy 闭环+救急支线同批→热更新深度+三阶段 gate 标定按反馈排期
