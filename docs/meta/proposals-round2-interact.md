## ④ 收益原则立场：**三禁**
1. 禁可重复数值收益（会被 160 周最优策略吸收为打卡，违反 DR-009+污染万周模拟断言）
2. 禁错过惩罚（不看零损失——对真空焦虑的反向定义）
3. 禁新增命令/信号/入档字段（首版）——用架构红线反推设计上限
- 收益只许三类：彩蛋型一次性 / 收集型观赏（接周目图鉴钩子）/ 氛围型
- 唯一放行通道（默认关闭）：试玩"想要摆弄有用"≥2/4 画像 → 启用 staff.condition 预埋——心情加成 ≤+5%、每周衰减归零、只能续不能叠、永不进 V1–V8 断言、V-sim 政策隔离双跑

## ⑤ 分级
- v0.1.0 可选顺手：F1 文本池 texts 加键（零风险）+PR9c 余量时接点击气泡（半天）
- v0.2 第一批（上限 3 个，试玩定向后）：F1 全量（30±条）+F2 抽屉+F3 翻面；**止损线 ≤3 人日/0 新命令/0 新信号/0 入档字段/文本 ≤80 键/动效 L1–L2 级**；任一超线砍到只剩 F1
- 试玩后观察池：F4 喂食/F5/F6 观赏版；F6 增益版永久封禁
