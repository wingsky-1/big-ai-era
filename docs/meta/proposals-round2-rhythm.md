## 议题 C：阶段推进条件与体验

**② 设计提案（玩家语言）**：前 24 周从周报逐渐听到"董事会打听成绩单"；满足任一硬指标后周报常驻"距离独角兽还差 X"；达标当周金框头条宣布注资、Dock 出现带"新"角标按钮；上市晋升=一局仅三次大动画之一（毕业典礼）。卡门不永远卡死（机会窗口降档），晋升后三条常驻目标线。

**③ 机制要点**
- gate 字段形态：stages.json 每 gate=谓词数组（隐式 AND，元素可一层 any_of），复用 predicate_registry 禁 DSL【DR-011/结构绿；新谓词 cum_income_gte/sota_wins_gte 成对注册=黄】
- gate 建议值：lab→独角兽=影响力≥50+累计经营收入≥250k（~锚 W24）；独角兽→上市=SOTA 夺冠≥3+累计经营收入≥1200k（~锚 W64）【R-9 锚 24/64】
- expected_p50=纯测试锚：nightly 断言 P50 晋级周∈[p50−10,p50+15]（宽占位 PR10 收窄）+兜底触发基准，不做 UI【绿】
- 重评频率维持每周【DR-007 已有】
- 进度可见：满足≥1 项 gate 条件起周报常驻差距行，全空不开（防倒计时压迫）【绿】
- 防卡死：week≥p50+30 追加"机会窗口"any_of 降档（阈值×0.7~），拟人化"投资人耐心"，正常玩家不触发【黄】
- 晋升仪式：lab→独角兽=金框头条+三行（新收入/支出预告/新解锁）+"新"角标；独角兽→上市=动用 L3 毕业典礼+特别版周报；**L3 三名额建议=首冠命名（UI8）/上市晋升/Game Over**【DR-020】
- 开箱感：新按钮首点=复用术语式一句话提示【绿】
- 自由期目标三线：霸榜连续周（flag 计数器）/树 n/14（TF5 已有）/影响力存量（300–600~）；summary 扩两列【绿】

**④ 数据/文案**：stages.json 形态 `{id, gate:[{pred,params}], expected_p50, fallback:{week_offset:30, mult:0.7}}`；**累计收入只计经营性收入（课题+复现+未来 API/支线），融资/IPO 不计**（防"融资冲 gate"镜像刷感）；texts 增 gate_progress_row/stage_up_headline/stage_up_unlock_row

**⑤ 分级**：v0.1.0 顺手=gate 谓词结构+stages.json 占位+宽区间断言（随 PR5）+霸榜计数器+差距行（随 PR9b）；v0.2 第一批=融资行/deploy 行/支线 3 卡真身+机会窗口降档；等试玩=gate 三值标定、L3 排面；储备=价格战、影响力里程碑

**C6 归属建议**：SG1–SG3 随 PR5 不单开（SG1/SG3 与谓词注册表互依；SG2 信号随 PR5、头条渲染随 PR9b）——单开小 PR 反制造跨 PR 依赖

**开放问题**：C① cum_income 口径=毛收入 vs 经营性收入（建议后者，需数值席确认与 R-9 原意一致）；C② L3 名额=首冠命名/上市晋升/Game Over，"实验室→独角兽"仅金框头条够不够仪式感？

## 议题 D：新手引导全案

**② 设计提案**：10 秒派第一个研究员上活；引导=贴目标旁不挡路的气泡，世界照常流淌；说话人=开场白老博导（周报作"博导手记"）；第一次快没钱/首次决策卡/首次深巷逼近各一句一次性人话解释；4x 挂 10 周回来先看"过去 12 周发生了 3 件事"；二周目直接干活。

**③ 机制要点**
- UI 形态：锚定气泡（非阻塞）为主+周报说话为纲；**否决高亮遮罩**（必拦流淌违 UI11）【绿】
- 口吻：博导人设延续+黑话挂术语提示【绿】
- 引导状态：flags.tutorial_step/done 零迁移；⚠**get_ui_snapshot 需增 tutorial{step,done} 小对象——须赶 PR5R 字段冻结前拍板，否则走迁移**【DR-021 B2】
- 归来摘要：触发 absent_weeks≥6（~）；形态=周报流聚合头"3 条大事+1 提醒"，点开=周报重看列表（z1 双挂载已有）；**零新系统**——View 层从已产 report 流挑 3 条（权重：晋升>冠位易主>翻雾>警告线>未决卡），不入档；last_seen_week 入 flags；注意停喂已裁，真实场景=4x 挂机/重开读档【绿】
- 二周目豁免：user://meta.cfg（周目数/曾达最高阶段/已读教学集），不进 SaveMigrator 链；降级=曾达独角兽→W0–2 气泡全跳、教学链改普通任务；叙事与术语不豁免；为周目三件套预埋容器【绿】
