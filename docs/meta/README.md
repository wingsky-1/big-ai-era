## 使用约定

- 新会议的席位提案/画像审视/议程继续按 `proposals-*/voices-*` 前缀落本目录
- 唤起 prompt 模板复用 `2026-09-07-lead-programmer-revival-prompt.md` 结构
  （开工三步/关键锚点/回合纪律），换项目时替换仓库路径与锚点
- 主持人裁决草案（chair-draft）若含未拍板事项，归档前先核对是否已全部进正式纪要
