### PT-154 · issue #154 新玩家无指导走通 W1→W10 首循环且想截图

- **前置**：新局开局（欢迎头条可跳过，目标卡不可关）；引导期 1x 速度。
- **操作**：
  1. 不读任何文档，从新局开始（观察：目标卡第 1 格"接第一单"）。
  2. 跟随目标卡自然走完：接单 → 点树 → 攒影响力 → 排训练 → 出分并命名 → 迎战首个对手。
  3. 首出分命名完成后，停顿观察目标卡是否自动翻新指向下一步（迎战首个对手）。
  4. W10 首对手周报出现后，尝试点"查看差距"（如可达）。
- **预期**：全程无卡死/无需要说明书才懂的门；首出分瞬间"想截图"；出分命名后 5 秒内知道下一步；目标卡任意时刻 ≤2 击说清"还差几周"。
- **代理指标**：①W1→W10 六步目标卡全部达成且无空等（达成周 ≤ 节拍锚 [1,3,3,4,8,10]，见 PT-152）；②首出分命名后 ≤5s 说得出"接下来要迎战首对手"；③目标卡点击 ≤2 击得到"约再跑 X 周"（onb_week_hint 口径）；④试玩者原话含"想截图/再来一局"类意愿表述。
